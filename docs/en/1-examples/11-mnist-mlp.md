# Examples: 11 — MNIST MLP

Machine learning with the **`ml`** package (installed separately, not built into DataCode).

## Installation

```bash
dpm add ml
```

Repository: [ML-Datacode-lib](https://github.com/igornet0/ML-Datacode-lib) · documentation: [2-language/modules/ml-module](../2-language/modules/ml-module.md)

Example `.dc` files — in the [examples/](https://github.com/igornet0/ML-Datacode-lib/tree/main/examples) folder of the package repository (there is no separate `examples/en/11-mnist-mlp/` folder in the main DataCode repository).

```bash
# after dpm add ml and building libml
datacode path/to/ml/examples/mnist_mlp.dc
```

| Typical files in ML-Datacode-lib | Description |
|----------------------------------|-------------|
| `mnist_mlp.dc` | MLP training on MNIST |
| `mnist_model_demo.dc` | model demonstration |
