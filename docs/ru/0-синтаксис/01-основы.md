# Основы синтаксиса

Минимальный набор конструкций для первых программ на DataCode.

## Вывод на экран

```datacode
print("Привет, DataCode!")

```

## Переменные

```datacode
x = 42
name = "ДатаКод"
flag = true

```

### Три способа объявить переменную

| Запись | Где | Эффект |
|--------|-----|--------|
| `x = …` | верхний уровень скрипта | неявная **глобальная** переменная |
| `global x = …` | где угодно | явная **глобальная** переменная |
| `let x = …` | верхний уровень | тоже **глобальная** (как `x = …`) |
| `let x = …` | внутри функции | новая **локальная** переменная в этой функции |

На верхнем уровне скрипта `x = 42` и `let x = 42` ведут себя одинаково: переменная попадает в общее глобальное пространство имён.

### `global` — явная глобальная переменная

```datacode
global counter = 0

fn inc() {
    global counter = counter + 1
}

```

`global counter = …` внутри функции нужен, когда переменная **ещё не объявлена** на верхнем уровне, или когда вы явно хотите записать в глобал (как в примере с инкрементом).

Если переменная уже объявлена глобально (`global x = …` или `let x = …` / `x = …` на верхнем уровне), присваивание **`x = …` внутри функции изменяет глобальную `x`**, а не создаёт локальную копию.

### `let` — локальная переменная внутри функции

Ключевое слово **`let`** внутри функции создаёт **новую локальную** переменную, которая **затеняет** одноимённую глобальную. Изменения локальной переменной **не затрагивают** глобальную.

### Пример: вложенные функции (522 vs 900)

Классический пример из тестов VM — две версии одного кода. Отличие только в том, используется ли `let` для `y` внутри функций.

**С `let` — результат `522`:**

```datacode
global x = 1
let y = 2
fn outer() {
    x = 10
    let y = 20          # локальная y в outer, глобальная y остаётся 2
    fn inner() {
        x = 100         # глобальная x
        let y = 200     # локальная y в inner
        return x + y    # 100 + 200 = 300
    }
    return inner() + x + y   # 300 + 100 + 20 = 420
}
outer() + x + y              # 420 + 100 + 2 = 522

```

**Без `let` (только `y = …`) — результат `900`:**

```datacode
global x = 1
let y = 2
fn outer() {
    x = 10
    y = 20              # y уже глобальная → y = 20 для всех
    fn inner() {
        x = 100
        y = 200         # глобальная y = 200
        return x + y    # 300
    }
    return inner() + x + y   # 300 + 100 + 200 = 600
}
outer() + x + y              # 600 + 100 + 200 = 900

```

Пошагово для варианта **с `let`**:

| Шаг | Что происходит |
|-----|----------------|
| `inner()` | `x = 100` (глобально), локальная `y = 200` → возвращает **300** |
| конец `outer()` | 300 + `x`(100) + локальная `y`(20) = **420** |
| верхний уровень | 420 + `x`(100) + глобальная `y`(2) = **522** |

Пошагово для варианта **без `let`**:

| Шаг | Что происходит |
|-----|----------------|
| `inner()` | глобальные `x = 100`, `y = 200` → **300** |
| конец `outer()` | 300 + 100 + 200 = **600** |
| верхний уровень | 600 + 100 + 200 = **900** |

**Правило:** внутри функции **`let y = …`** всегда создаёт локальную `y`. Присваивание **`y = …`** без `let` обновляет **глобальную** `y`, если она уже существует (объявлена через `global`, `let` или `=` на верхнем уровне). Если глобальной `y` нет — `y = …` создаёт новую локальную переменную.

Для **`x`** в обоих вариантах: `global x = 1` делает `x` глобальной, поэтому `x = 10` и `x = 100` внутри функций меняют одну и ту же глобальную переменную.

### Краткая шпаргалка

```datacode
global shared = 0     # явный глобал

fn example() {
    let local = 1     # локальная, не видна снаружи
    shared = 2        # меняет глобальную shared (она уже объявлена)
    temp = 3          # новая локальная (глобальной temp нет)
}

```
