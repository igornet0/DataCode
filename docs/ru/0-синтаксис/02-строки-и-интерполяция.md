# Форматирование строк (интерполяция)

В DataCode строки поддерживают **интерполяцию**: подстановку значений переменных и выражений внутрь строки в формате `${...}`. Доступны варианты с выводом имени переменной и с форматированием (ширина, выравнивание, точность, разделители тысяч, проценты, экспонента).

## Базовая интерполяция

Внутри строки в двойных кавычках можно использовать `${выражение}`. Выражение вычисляется, и его значение подставляется в строку (как при преобразовании в строку).

```datacode
name = "Игорь"
"Привет, ${name}!"   # "Привет, Игорь!"

a = 2
b = 3
"результат: ${a + b}"   # "результат: 5"

```

Поддерживаются любые выражения: переменные, вызовы функций, арифметика, доступ к свойствам и т.д.

---

## Вывод «имя=значение»

Синтаксис **`${переменная=}`** выводит не только значение, но и имя в виде `имя=значение`. Удобно для отладочного вывода и логов.

```datacode
n = 42
b = true
"${b=} ${n=}"   # "b=true n=42"

```

Для сложных выражений в качестве «имени» используется текст выражения (например, `a+b=5`).

## Форматирование чисел

Синтаксис **`${выражение:формат}`** задаёт формат вывода. Спецификатор — подмножество мини-языка форматов Python:

```
[[заполнитель]выравнивание][знак][#][0][ширина][группировка][.точность][тип]
```

| Часть | Значения | Описание |
|-------|----------|----------|
| выравнивание | `<` `>` `^` `=` | влево, вправо, по центру, `=` — отступ между знаком и цифрами |
| заполнитель | любой символ | ставится перед выравниванием (`*^10`), по умолчанию пробел |
| знак | `+` `-` | `+` — всегда выводить знак, `-` — только у отрицательных (по умолчанию) |
| `#` | — | с `.0f`/`.0e` сохраняет десятичную точку (`3.`) |
| `0` | — | дополнение нулями после знака (`08d` → `-0000042`) |
| ширина | число | **минимальная** ширина поля; длинные значения не обрезаются |
| группировка | `,` `_` | разделитель тысяч в целой части |
| `.точность` | число | знаков после запятой; для строк — максимальная длина |
| тип | `f` `F` `e` `E` `d` `%` `s` | см. таблицу ниже |

| Тип | Описание | Пример | Результат |
|-----|----------|--------|-----------|
| `f` / `F` | фиксированная точка (по умолчанию 6 знаков) | `${42.23425:.2f}` | `42.23` |
| `e` / `E` | экспоненциальная запись | `${150:.2e}` | `1.50e+02` |
| `d` | целое число (float без дробной части тоже подходит) | `${42:08d}` | `00000042` |
| `%` | умножает на 100 и добавляет `%` | `${0.256:.1%}` | `25.6%` |
| `s` | строка (точность обрезает) | `${w:.4s}` при `w = "datacode"` | `data` |
| без типа | обычное строковое представление | `${s:>6}` при `s = "ab"` | `    ab` |

```datacode
n = 42.23425
"${n:.2f}"            # "42.23"
"${n:.0f}"            # "42"
"[${n:9.2f}]"         # "[    42.23]"  — числа по умолчанию выравниваются вправо
"[${n:<9.2f}]"        # "[42.23    ]"
"[${n:^9.1f}]"        # "[  42.2   ]"

s = "ab"
"[${s:5}]"            # "[ab   ]"      — нечисловые значения выравниваются влево
"[${s:>6}]"           # "[    ab]"
"[${s:*^6}]"          # "[**ab**]"

"${1234567.891:,.2f}" # "1,234,567.89"
"${1234567:_d}"       # "1_234_567"
"${7:+d}"             # "+7"
"[${-3.5:=+8.1f}]"    # "[-    3.5]"
"${0.256:.1%}"        # "25.6%"
"${150:.2E}"          # "1.50E+02"
"${3:#.0f}"           # "3."
```

Правила:

- Если значение не подходит под тип (строка с `f`, дробное число с `d`), выводится его обычное строковое представление — с учётом ширины и выравнивания: `${s:.2f}` → `ab`, `${5.5:d}` → `5.5`.
- Двоеточие внутри `[...]` не считается началом формата: `${path[:5]}` — это срез.
- Спецификатор, который не распознан как формат (например `${n:abc}`), — ошибка разбора строки.

## Комбинирование

Можно одновременно выводить имя и применять формат: **`${переменная=:формат}`**.

```datacode
n = 42.23425
"${n=:.0f}"     # "n=42"
"${n=:.2f}"     # "n=42.23"
"${n=:>10.2f}"  # "n=     42.23"

```

Порядок: сначала выражение, затем необязательный суффикс `=`, затем необязательный `:формат`.

---

## Экранирование

Чтобы вставить в строку буквальную последовательность `${` (без интерполяции), экранируйте символ доллара: **`\${`**. В результате в строку попадёт `${`.

```datacode
"Синтаксис: \${expr}"   # "Синтаксис: ${expr}"

```

## Краткая справка

| Синтаксис           | Результат (пример)      |
|---------------------|-------------------------|
| `${x}`              | значение выражения      |
| `${x=}`             | `x=значение`            |
| `${x:.2f}`          | число с 2 знаками после запятой |
| `${x=:.0f}`         | `x=42` (имя и целое)     |
| `${x:9.2f}`         | ширина 9, 2 знака, вправо |
| `${s:*^10}`         | по центру, заполнитель `*` |
| `${x:,.2f}`         | `1,234,567.89`          |
| `${x:08d}`          | `00000042`              |
| `${x:.1%}`          | `25.6%`                 |
| `${x:.2e}`          | `1.50e+02`              |
