# Массивы

Упорядоченный изменяемый список значений. Элементы перечисляются через запятую в квадратных скобках; индексация и срезы — в стиле Python.

**Семантика типов, методы и встроенные функции** (`push`, `map`, `enum`, …): [2-язык/типы-данных/массивы](../2-язык/типы-данных/массивы.md).

---

## Литерал `[ … ]`

```datacode
empty = []
nums = [1, 2, 3]
mixed = [1, "two", true, null]
nested = [[1, 2], [3, 4]]

```

После последнего элемента запятая допустима: `[1, 2, 3,]`.

Элементами могут быть любые выражения:

```datacode
n = 3
row = [n * 2, n + 1, "x"]

```

---

## Другие способы создать массив

```datacode
a = array(10, 20, 30)           # из аргументов
b = array_with_capacity(100)    # пустой, с запасом памяти
c = range(5)                    # ленивый итератор 0..4 (не массив)
d = range(1, 11)                # 1..10
e = range(0, 10, 2)             # 0, 2, 4, 6, 8
arr = array(range(n))           # материализовать в массив с индексацией arr[i]

```

`range(...)` возвращает **ленивый итератор** (`Iterable`): память O(1), элементы выдаются в `for … in range(…)` и в list comprehension.  
`len(range(a, b))` и `len(range(a, b, step))` считают длину по формуле без построения массива.  
Аргументы — целые `int` или целые `number` (например `1 << n`); дробный литерал `5.0` не принимается.  
`range(stop)` — от `0` до `stop` **не включая** `stop`.  
`range(start, stop)` и `range(start, stop, step)` работают так же: верхняя граница не входит в результат. Шаг не может быть `0`.

---

## Индекс `arr[i]`

```datacode
v = [10, 20, 30, 40]
print(v[0])       # 10
print(v[2])       # 30
print(v[-1])      # 40 — последний элемент
print(v[-2])      # 30

```

Отрицательный индекс отсчитывается с конца массива.

**Запись по индексу** изменяет исходный массив:

```datacode
arr = [1, 2, 3]
arr[0] = 9
print(arr)        # [9, 2, 3]

```

---

## Срезы `arr[start:stop:step]`

Тот же синтаксис работает и для **строк** (`str`); подробнее — [типы-данных/строка.md](../2-язык/типы-данных/строка.md#срез-sstartstopstep).

Синтаксис как в Python. Пропущенные границы означают «от начала» / «до конца»:

| Запись | Смысл |
|--------|--------|
| `arr[a:b]` | элементы с индекса `a` до `b` **не включая** `b` |
| `arr[:]` | весь массив (view — «окно» без копирования данных) |
| `arr[::2]` | каждый второй элемент |
| `arr[::-1]` | элементы в обратном порядке |
| `arr[2:6:2]` | с индекса 2 до 6 с шагом 2 |

```datacode
a = [0, 1, 2, 3, 4, 5, 6, 7]
print(a[1:4])     # [1, 2, 3]
print(a[-3:])     # последние три
print(a[::2])     # [0, 2, 4, 6]

```

**Присваивание срезу** заменяет участок массива; пустой список справа удаляет элементы:

```datacode
arr = [1, 2, 3, 4, 5]
arr[1:3] = [20, 30]    # [1, 20, 30, 4, 5]
arr[1:4] = []          # удалить элементы с 1 по 3 → [1, 5]

```

Подробнее о представлении среза (view): [2-язык/типы-данных/массивы](../2-язык/типы-данных/массивы.md#представление-массива-срез-arrayview).

## List comprehension — `[ выражение for … ]`

Генератор списка в стиле Python: результат — **новый** массив.

### Простые формы

```datacode
squares = [x * x for x in [1, 2, 3]]           # [1, 4, 9]
zeros = [0 for _ in range(5)]                  # [0, 0, 0, 0, 0]
indexed = [x for x in range(10)]               # [0, 1, …, 9]
ones = [1 for _ in range(n)]                    # n единиц

```

Переменная `_` в заголовке `for` — обычное имя: значение итератора не используется, но цикл выполняется нужное число раз.

### Фильтр `if`

```datacode
evens = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]

```

### Несколько циклов `for`

Вложенные циклы перебираются слева направо (как в Python):

```datacode
grid = [x * y for x in [1, 2] for y in [10, 20]]
# [10, 20, 20, 40]

matrix = [[0 for _ in range(n + 1)] for _ in range(m + 1)]
# внешний и внутренний range — ленивые; итог — массив массивов

```

Вложенный comprehension, где элемент — другой comprehension (`[[e for _ in range(c)] for _ in range(r)]`), поддерживается так же, как в Python.

`if` между двумя `for` относится к ближайшему левому циклу:

```datacode
pairs = [100 * x + y for x in [1, 2] if x == 2 for y in [1, 2]]
# [201, 202]

```

### Распаковка в заголовке

```datacode
sums = [a + b for a, b in [[1, 2], [3, 4]]]    # [3, 7]
picked = [weights[i] for i in items]

```

Поддерживаются те же паттерны, что и в `for … in …`: `for x in`, `for x, y in`, `for (x, y) in`, `for [x, y] in`, `for x, _, y in`.

### Область видимости

Переменные, введённые в comprehension, **не** меняют одноимённые переменные снаружи:

```datacode
x = 100
a = [x for x in [1, 2]]
print(x)    # 100

```

## Перебор в цикле `for`

Массив — итерируемое значение:

```datacode
for i in [1, 2, 3, 4, 5] {
    print(i)
}

for i in range(5) {
    print(i)
}

for ch in parts {
    print(len(ch), ch)
}

```

С индексом — через `enum`:

```datacode
for i, item in enum([10, 20, 30]) {
    print(i, item)
}

```

Подробнее: [циклы](./05-циклы.md).

## Изменение массива

Массив **изменяемый**: несколько переменных могут ссылаться на один и тот же список.

```datacode
a = [1]
b = a
push(a, 2)
print(b)        # [1, 2] — видно и в b

stack = [1, 2, 3]
push(stack, 4)
stack.push(5)   # метод или глобальная функция

```

Добавление, удаление, сортировка и агрегаты — в [2-язык/типы-данных/массивы](../2-язык/типы-данных/массивы.md) и в примере `массивы.dc`.
