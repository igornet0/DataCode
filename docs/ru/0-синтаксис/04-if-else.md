# Условия: if / else

Управление потоком выполнения по условию. Условие может быть явным сравнением (`x > 0`) или любым значением — в этом случае используется **истинность** (truthiness), см. [ниже](#истинность-в-условиях).

## Базовый синтаксис

### `if` без `else`

```datacode
if x > 5 {
    print("x больше 5")
}

```

Блок выполняется только когда условие истинно. Если условие ложно — выполнение просто продолжается дальше.

### `if` / `else`

```datacode
if x > y {
    print("x больше y")
} else {
    print("x не больше y")
}

```

### Цепочка `else if`

```datacode
if a > 0 {
    print("положительное")
} else if a < 0 {
    print("отрицательное")
} else {
    print("ноль")
}

```

`else if` — это `else`, за которым сразу идёт новый `if`. Веток может быть сколько угодно; последняя `else` необязательна.

## Однострочный `if` (через `:`)

Для коротких веток можно писать одну инструкцию после двоеточия — без фигурных скобок:

```datacode
if x > 0: return 1
if x == 0: x = 10
if !(0 <= nr < rows and 0 <= nc < cols): continue

```

Удобно в функциях и циклах для раннего выхода (`return`, `continue`, `break`) или простого присваивания. Полный блок по-прежнему записывается через `{ ... }`.

## Истинность в условиях

В `if`, `while` и тернарных выражениях значение приводится к «истине» или «ложи»:

| Ложь (falsy) | Истина (truthy) |
|--------------|-----------------|
| `null`, `false` | `true` |
| число `0` | любое ненулевое число |
| пустая строка `""` | непустая строка |
| пустой массив `[]`, пустой объект | непустые коллекции |
| пустая таблица | объекты среды (окна, движки БД и т.д.) |

```datacode
items = []
if items {
    print("есть элементы")   # не выполнится
} else {
    print("список пуст")
}

if flag {                    # flag: bool
    print("включено")
}

```

Подробнее о типах: [числа, логика и null](../2-язык/типы-данных/числа-логика-null.md).

## Операторы сравнения

| Оператор | Значение |
|----------|----------|
| `==` | равно |
| `!=` | не равно |
| `>`, `<` | больше, меньше |
| `>=`, `<=` | больше или равно, меньше или равно |

```datacode
if name1 == name2 {
    print("Имена одинаковые")
}

if value != null {
    print(value)
}

```

### Цепочки сравнений

Как в Python, можно писать несколько сравнений подряд — они объединяются через `and`:

```datacode
if 0 <= age and age < 18 {
    print("несовершеннолетний")
}

if 0 <= nr and nr < rows and 0 <= nc and nc < cols {
    // ячейка внутри сетки
}

```

Краткая запись границ: `0 <= x < n` эквивалентна `0 <= x and x < n`.

## Логические операторы

```datacode
ok = true
not_ok = !ok

if x != null and x > 0 {
    print(x)
}

if blocked or timeout {
    print("прервать")
}

if !(a < b and b < c) {
    print("цепочка нарушена")
}

```

| Оператор | Значение |
|----------|----------|
| `and` | логическое «и» (короткое замыкание) |
| `or` | логическое «или» (короткое замыкание) |
| `!` | отрицание |

Для **битовых масок** используйте побитовые операторы `&`, `|`, `^`, `~`, `<<`, `>>` (см. [побитовые-операторы.md](./10-побитовые-операторы.md)), а не `and` / `or`.

Литералы: `true`, `false`.

Оператор **`in`** проверяет принадлежность элементу коллекции:

```datacode
if 5 in [1, 2, 3, 4, 5] {
    print("найдено")
}

```

Оператор **`not in`** проверяет принадлижит элементу коллекции, если да -> false:

```datacode
if 5 not in [1, 2, 3, 4, 5] {
    print("найдено")
}

```

## `if` как выражение

Когда нужно **получить значение**, а не выполнить блок инструкций, используйте `if` / `else` с фигурными скобками в **позиции выражения**:

```datacode
status = if got == expected { "OK" } else { "FAIL" }
cost = if a[i - 1] == b[j - 1] { 0 } else { 1 }
label = if n > 0 { "есть" } else { "пусто" }

print("Результат: ${if x > 0 { "плюс" } else { "минус" }}")

```

Обе ветки обязательны. Внутри `{ ... }` может быть несколько строк; значением ветки становится результат **последнего** выражения в блоке.

В `return` и других выражениях:

```datacode
fn sign(n) {
    return if n > 0 { 1 } else { if n < 0 { -1 } else { 0 } }
}

```

### Альтернатива: Python-тернарный синтаксис

Поддерживается также форма `значение_если_истина if условие else значение_если_ложь`:

```datacode
x = 1 if true else 2
return dp[amount] if dp[amount] != INF else -1

```

`if` и `else` в этой форме должны быть **на одной строке** с выражением (нет неявного переноса строки). Для многострочных веток предпочтительнее блочная форма `if ... { ... } else { ... }`.

### C-style тернарный синтаксис `? :`

Форма `условие ? значение_если_истина : значение_если_ложь` (как в C, JavaScript, Rust):

```datacode
x = true ? 1 : 2
to_bool = fn(s) => s == "yes" ? true : s == "no" ? false : bool(s)

```

| Python | C-style |
|--------|---------|
| `1 if cond else 2` | `cond ? 1 : 2` |
| `a if b else c if d else e` | `b ? a : d ? c : e` |

Свойства:

- **Правая ассоциативность:** `a ? b : c ? d : e` → `a ? b : (c ? d : e)`
- **Приоритет** ниже арифметики: `1 + 2 ? 3 : 4` → `(1 + 2) ? 3 : 4`
- **Short-circuit:** невыбранная ветка не вычисляется
- Перенос строки **разрешён** (в отличие от Python-формы с `if`/`else` на одной строке)
- Обе формы можно комбинировать в одном выражении

## Типичные паттерны

### Вложенные условия

```datacode
if age >= 18 {
    if age < 65 {
        print("Взрослый")
    } else {
        print("Пенсионер")
    }
} else {
    print("Несовершеннолетний")
}

```

### Проверка на `null` перед использованием

```datacode
if env != null {
    print(env["HOST"])
}

```

### Ранний выход из функции

```datacode
fn divide(a, b) {
    if b == 0: return null
    return a / b
}

```

### Условие внутри цикла

```datacode
for i in items {
    if i == skip: continue
    if i < 0: break
    print(i)
}

```
