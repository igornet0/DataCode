# Функции

Именованные блоки кода с параметрами и возвращаемым значением.

## Объявление и вызов

```datacode
fn greet(name) {
    return "Привет, " + name + "!"
}

print(greet("DataCode"))

```

## Параметры по умолчанию

```datacode
fn power(base, exp = 2) {
    result = 1
    for _ in range(exp) {
        result = result * base
    }
    return result
}

```

Значение по умолчанию может быть **литералом** или **выражением из compile-time констант модуля** (имена, присвоенные на верхнем уровне до объявления функции):

```datacode
BASE = 10

fn mul(x, n = BASE) {
    return x * n
}

print(mul(5))   # 50
BASE = 99       # не меняет default у уже скомпилированной mul
print(mul(5))   # по-прежнему 50
```

Default фиксируется при компиляции определения функции (как в Python). Нельзя ссылаться на параметры той же сигнатуры, на forward reference (`fn f(x = RED)` до `RED = 0`) или на runtime-значения (`RED = read_config()`).

## Переменное число аргументов: `*args` и `**kwargs`

Параметр со звёздочкой собирает «лишние» аргументы вызова:

- **`*имя`** — все позиционные аргументы, которым не хватило обычных параметров, в **массив**;
- **`**имя`** — все именованные аргументы, которым не нашлось параметра с таким именем, в **объект** (словарь).

```datacode
fn total(*nums) {
    s = 0
    for n in nums {
        s = s + n
    }
    return s
}

print(total())         # 0
print(total(1, 2, 3))  # 6

fn connect(host, **opts) {
    port = opts.get("port", 5432)
    return host + ":" + str(port)
}

print(connect("db"))               # db:5432
print(connect("db", port = 6000))  # db:6000
```

Порядок параметров: обычные → со значением по умолчанию → `*args` → `**kwargs`. Каждый из `*args` и `**kwargs` может встретиться не больше одного раза, и у них нет значения по умолчанию (без аргументов это пустой массив `[]` и пустой объект `{}`):

```datacode
fn log(level, prefix = ">", *parts, **meta) {
    return prefix + " " + level + ": " + join(parts, " ")
}

print(log("INFO"))                        # > INFO:
print(log("INFO", "#", "сервер", "готов"))  # # INFO: сервер готов
```

### Распаковка при вызове

При вызове `*массив` раскладывает элементы в позиционные аргументы, а `**объект` — пары ключ-значение в именованные:

```datacode
fn point(x, y, z) {
    return [x, y, z]
}

coords = [1, 2]
print(point(0, *coords))                # [0, 1, 2]
print(point(*[1], *[2, 3]))             # [1, 2, 3]
print(point(1, **{"y": 20, "z": 30}))   # [1, 20, 30]

# Проброс всех аргументов дальше
fn wrapper(*args, **kwargs) {
    return point(*args, **kwargs)
}
```

Аргументы при вызове пишутся в порядке: позиционные → `*массив` → именованные и `**объект`.

Полные правила связывания аргументов, ошибки и ограничения: [функции — аргументы вызова](../2-язык/типы-данных/функции.md#аргументы-вызова-args-и-kwargs).

## return

```datacode
fn abs(x) {
    if x < 0 {
        return -x
    }
    return x
}

```

```datacode
fn abs(x) {
    return x if x > 0 else -x
}

```

Без `return` функция возвращает `null`.

## Вложенные функции

```datacode
fn outer() {
    fn inner(x) {
        return x * 2
    }
    return inner(21)
}

```

Правила захвата переменных: [области видимости и замыкания](../2-язык/области-видимости-и-замыкания.md).
