# Функции

Именованные блоки кода с параметрами и возвращаемым значением.

## Объявление и вызов

```datacode
fn greet(name) {
    return "Привет, " + name + "!"
}

print(greet("DataCode"))

```

## Параметры по умолчанию

```datacode
fn power(base, exp = 2) {
    result = 1
    for _ in range(exp) {
        result = result * base
    }
    return result
}

```

Значение по умолчанию может быть **литералом** или **выражением из compile-time констант модуля** (имена, присвоенные на верхнем уровне до объявления функции):

```datacode
BASE = 10

fn mul(x, n = BASE) {
    return x * n
}

print(mul(5))   # 50
BASE = 99       # не меняет default у уже скомпилированной mul
print(mul(5))   # по-прежнему 50
```

Default фиксируется при компиляции определения функции (как в Python). Нельзя ссылаться на параметры той же сигнатуры, на forward reference (`fn f(x = RED)` до `RED = 0`) или на runtime-значения (`RED = read_config()`).

## return

```datacode
fn abs(x) {
    if x < 0 {
        return -x
    }
    return x
}

```

```datacode
fn abs(x) {
    return x if x > 0 else -x
}

```

Без `return` функция возвращает `null`.

## Вложенные функции

```datacode
fn outer() {
    fn inner(x) {
        return x * 2
    }
    return inner(21)
}

```

Правила захвата переменных: [области видимости и замыкания](../2-язык/области-видимости-и-замыкания.md).

## Типизированные функции

Аннотации параметров и возвращаемого типа:

```datacode
fn add(a: int, b: int) -> int {
    return a + b
}

```

Полное руководство: [типизированные-функции](./07-типизированные-функции.md).
