# Побитовые операторы

Операторы для работы с целыми числами на уровне битов. Поддерживаются только операнды типа **`int`** (целочисленные литералы без дробной части и переменные `int`). Для `float`, `string`, `bool`, массивов и объектов — ошибка времени выполнения:

`Bitwise operator is supported only for int values`

## Операторы

| Оператор | Значение | Пример |
|----------|----------|--------|
| `a & b` | побитовое И | `5 & 3` → `1` |
| `a \| b` | побитовое ИЛИ | `5 \| 3` → `7` |
| `a ^ b` | исключающее ИЛИ | `5 ^ 3` → `6` |
| `~a` | побитовое НЕ | `~5` → `-6` |
| `a << b` | сдвиг влево | `1 << 5` → `32` |
| `a >> b` | сдвиг вправо (арифметический) | `32 >> 2` → `8` |

Литерал `5.0` имеет тип `float` и **не** допускается в побитовых выражениях, даже если дробная часть нулевая.

## Приоритет

От высокого к низкому (фрагмент):

1. `~` (унарный)
2. `<<`, `>>`
3. `&`
4. `^`
5. `|`
6. `+`, `-` (выше сдвигов по связанности с арифметикой: `1 << 2 + 1` = `1 << (2 + 1)` = `8`)

Логические `and`, `or`, `!` — отдельные операторы для условий; для битовых масок используйте `&`, `|`, `~`.

## Примеры

```datacode
# Проверка бита
if mask & (1 << i) {
    print("bit set")
}

# Установка / сброс / переключение
mask = mask | (1 << i)
mask = mask & ~(1 << i)
mask = mask ^ (1 << i)
```
