# Обработка ошибок

Исключения: `try`, `catch`, `throw`, `finally`.

## try / catch

```datacode
try {
    x = 1 / 0
} catch (e) {
    print("Ошибка:", e)
}

```

Переменная в `catch (e)` необязательна:

```datacode
try {
    risky()
} catch {
    print("что-то пошло не так")
}

```

## throw

```datacode
fn validate(x) {
    if x < 0 {
        throw "отрицательное значение"
    }
    return x
}

```

## finally

```datacode
try {
    open_and_process()
} catch (e) {
    log(e)
} finally {
    cleanup()
}

```

Блок `finally` выполняется всегда — и при успехе, и при ошибке.

## Вложенные try

```datacode
try {
    try {
        work()
    } catch (inner) {
        throw "обёрнутая ошибка: " + str(inner)
    }
} catch (outer) {
    print(outer)
}

```
