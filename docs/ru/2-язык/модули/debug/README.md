# Модуль debug — отладка рантайма

Встроенный модуль для **интроспекции** VM. Предназначен для разработчиков и отладки, не для продакшен-логики.

## Импорт

```datacode
import debug
```

## debug.operators() -> string

Возвращает текстовую таблицу зарегистрированных **инфиксных операторов** (symbol, name, precedence, associativity, модуль-источник).

Требует, чтобы хост VM установил снимок реестра операторов при старте (`Vm::set_operator_registry_snapshot`). При обычном запуске `datacode` таблица доступна после `import debug`.

```datacode
import debug
print(debug.operators())
```

Если снимок не задан, возвращается поясняющее сообщение вместо таблицы.
