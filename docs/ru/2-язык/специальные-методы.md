# Специальные методы класса (@-methods)

Специальные методы — это методы класса с именем вида `@имя`. Они **не вызываются напрямую** из пользовательского кода (`obj.@string()`, `@add(...)`), а подключаются компилятором и виртуальной машиной к операторам, встроенным функциям и протоколам итерации.

**Пример:** [`examples/ru/02-синтаксис/методы-операции.dc`](../../../examples/ru/02-синтаксис/методы-операции.dc)

**См. также:** [Классы (синтаксис)](../0-синтаксис/09-классы.md)

## Объявление

Внутри тела `cls` после `fn` можно указать имя с префиксом `@`:

```datacode
cls Vector {
    x: float
    y: float
    new Vector(x: float, y: float) {
        this.x = x
        this.y = y
    }
    fn @add(other: Vector) -> Vector {
        return Vector(this.x + other.x, this.y + other.y)
    }
    fn @string() -> str {
        return "Vector(" + str(this.x) + ", " + str(this.y) + ")"
    }
    fn @len() -> int {
        return 2
    }
}
```

После определения класса операторы и builtins работают через эти методы:

```datacode
v1 = Vector(1, 2)
v2 = Vector(3, 4)
v3 = v1 + v2          # Vector.@add
print(v3)             # Vector.@string
print(len(v3))        # Vector.@len  → 2
```

## Таблица методов

| Метод | Когда вызывается | Сигнатура (без `this`) | Возврат |
|-------|------------------|------------------------|---------|
| `@string` | `str(x)`, `print(x)` для экземпляра | `()` | `str` |
| `@len` | `len(x)` | `()` | `int` |
| `@add` | `a + b` | `(other)` | любой |
| `@sub` | `a - b` | `(other)` | любой |
| `@mul` | `a * b` | `(other)` | любой |
| `@div` | `a / b` | `(other)` | любой |
| `@mod` | `a % b` | `(other)` | любой |
| `@pow` | `a ^ b` | `(other)` | любой |
| `@eq` | `a == b` | `(other)` | `bool` / `logic` |
| `@neq` | `a != b` | `(other)` | `bool` / `logic` |
| `@lt` | `a < b` | `(other)` | `bool` / `logic` |
| `@lte` | `a <= b` | `(other)` | `bool` / `logic` |
| `@gt` | `a > b` | `(other)` | `bool` / `logic` |
| `@gte` | `a >= b` | `(other)` | `bool` / `logic` |
| `@get` | `obj[key]` (если нет поля с таким именем) | `(key)` | любой |
| `@set` | `obj[key] = value` | `(key, value)` | `null` / void |
| `@contains` | `value in obj` | `(member)` | `bool` |
| `@call` | `obj(...)` | variadic | любой |
| `@iter` | `for x in obj` | `()` | итератор / `self` |
| `@next` | шаг `for-in` | `()` | элемент; `null` = конец |
| `@clone` | `obj.clone()` | `()` | копия |
| `@hash` | ключ в `set` / `dict` | `()` | `int` |
| `@init` | после тела конструктора | как у конструктора | `null` / void |
| `@drop` | — | — | **зарезервирован, не реализован** |

Неверная сигнатура отклоняется на этапе компиляции, например: `` `@len` must take 0 arguments ``.

## Пример Vector

Полный рабочий пример — в файле [`методы-операции.dc`](../../../examples/ru/02-синтаксис/методы-операции.dc).

Кратко:

```datacode
v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)   # Vector(4.0, 6.0)
print(len(v1))   # 2
```

## Ограничения

- **Прямой вызов запрещён:** `v.@string()`, `@len(v)` → ошибка компиляции (*Special methods cannot be called directly*).
- **Только внутри `cls`:** `fn @add` на верхнем уровне файла недопустим.
- **Без `@`-метода** срабатывает обычное поведение VM (например, `a + b` для класса без `@add` → ошибка вроде *Operands must be numbers or strings*).
- **`@hash` без `@eq`:** для корректной работы в `set` обычно нужны оба метода.
- **Итерация:** для `for x in obj` нужны **оба** `@iter` и `@next`; `@next` возвращает `null`, когда элементов больше нет.

## @init и @drop

**`@init`** вызывается автоматически в конце каждого конструктора (после присвоения полей), с теми же параметрами, что у конструктора (без `this`):

```datacode
cls Widget {
    ready: bool
    new Widget() { this.ready = false }
    fn @init() { this.ready = true }
}
w = Widget()
# w.ready == true
```

**`@drop`** — имя зарезервировано для будущего деструктора; объявление `fn @drop()` сейчас даёт ошибку: *`@drop` is reserved but not implemented yet*.
