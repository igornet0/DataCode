# Типы данных в DataCode

Понятные описания типов: что это за значение, как обращаться (`[]`, методы), какие **встроенные функции** с ним работают.

**Технический справочник:** [справочник-типов.md](../справочник-типов.md) · **Встроенные функции:** [функции/](../функции/README.md) · **Синтаксис:** [0-синтаксис](../../0-синтаксис/README.md)

Техническая реализация в исходниках: тип значения `Value` в `src/common/value.rs`, обращение по индексу в `src/vm/interpreter/element/`, встроенные функции в `src/vm/native_registry.rs` и `src/vm/globals.rs`.

## С чего начать

1. **[typeof и isinstance](typeof-и-isinstance.md)** — как узнать тип и проверить его для **любого** значения, с примерами.
2. Дальше откройте нужный раздел по оглавлению ниже.
