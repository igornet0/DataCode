# `typeof` и `isinstance`: проверка типов

Кратко: **`typeof(x)`** возвращает **строку** с именем типа для отладки и логики. **`isinstance(x, тип)`** возвращает **`true`** или **`false`**, удобно в `if`.

Оба работают **со всеми значениями**, которые есть в языке: числа, строки, массивы, таблицы, функции, `null`, объекты классов, типы из графики/БД/плагинов и т.д.

---

## `typeof(x)`

Результат — строка, например `"int"`, `"array"`, `"table"`.

### Особенности

- **Числа:** без дробной части → `"int"`, с дробной → `"float"`.
- **Строки:** одна и та же строка в памяти может классифицироваться как `"date"` (если начало похоже на `YYYY-MM-DD`), как `"money"` (если есть `$`, `EUR`, `€`) или как обычная `"string"`.
- **Объект плагина:** если задано поле `__plugin_namespace`, `typeof` может вернуть это имя вместо `"object"`.
- **Неочевидные имена:** движок БД — `"database_engine"`, кластер — `"database_cluster"`, ссылка на колонку таблицы — `"column"`, ссылка на несколько колонок — `"columns"`.

### Примеры

```dc
print(typeof(42))           # int
print(typeof(3.14))         # float
print(typeof("hello"))      # string
print(typeof([1, 2]))        # array
print(typeof(null))          # null

```

---

## `isinstance(x, второй_аргумент)`

Возвращает **`true`**, если значение `x` соответствует указанному типу, и **`false`** в противном случае (или если аргументов меньше двух).

### Как задать второй аргумент

1. **Строка** — имя типа (регистр не важен):  
   `isinstance(x, "array")`, `isinstance(x, "table")`, `isinstance(x, "null")`.

2. **«Конструктор» типа из глобалов** — для удобства можно передать встроенную функцию, которая трактуется как имя типа:  
   `isinstance(x, int)`, `isinstance(x, str)`, `isinstance(x, array)`, `isinstance(x, Table)` и т.п. (см. реализацию: индексы нативов `int`, `str`, `array`, `Table` в `native_isinstance`).

3. **Объект класса** — для проверки **наследования** (экземпляр класса, таблица как `Table`):  
   второй аргумент — значение класса с полем `__class_name`. Тогда для **`Value::Table`** проверяется совпадение с классом `"Table"`, для **объекта** — цепочка класса / флаг наследования от таблицы.

### Справочник строк для `isinstance`

| Значение `x` | Примеры подходящих имён типа (строка или синоним) |
|--------------|---------------------------------------------------|
| Целое число | `"int"`, `"integer"`, `"number"`, `"num"` |
| Дробное число | `"float"` (только если у числа есть дробная часть); для любого числа также срабатывают `"int"`, `"number"`, `"num"`; `"money"` — для любого числа |
| `true` / `false` | `"bool"`, `"boolean"` |
| Обычная строка | `"string"`, `"str"` |
| Строка-дата (формат `YYYY-MM-DD`…) | `"date"` |
| Строка с валютой | `"money"` |
| Массив или срез массива (view) | `"array"`, `"list"` |
| Байты (`sha256`, …) | `"bytes"` (также `"array"`, `"list"`) — см. [bytes.md](bytes.md) |
| Кортеж | `"tuple"` |
| Таблица | `"table"` |
| Объект-словарь | `"object"`, `"dict"`, `"dictionary"` |
| Объект класса, наследующего Table | `"table"` (если у объекта выставлен `__extends_table`) |
| Колонка таблицы | `"column"` |
| Несколько колонок таблицы | `"columns"` |
| `null` | `"null"`, `"none"` |
| Любая функция | `"function"` |
| Путь | `"path"` |
| UUID | `"uuid"` |
| `enum(...)` | `"enumerate"` |
| `...` (ellipsis) | `"ellipsis"` |
| Окно / картинка / фигура / ось | `"window"`, `"image"`, `"figure"`, `"axis"` |
| Движок БД / кластер | `"database_engine"`, `"database_cluster"` |
| Объект плагина (opaque) | `"plugin_opaque"` или имя типа, которое вернул плагин |
| Объект с `__plugin_namespace` | строка должна совпадать с этим пространством имён |

### Примеры

```dc
# Базовые проверки
print(isinstance(10, int))           # true
print(isinstance(10, float))         # false
print(isinstance(2.5, float))      # true
print(isinstance("ab", str))         # true
print(isinstance([1], array))        # true
print(isinstance(null, null))        # true

# Таблица
t = table(["a"], [[1]])
print(isinstance(t, table))          # true

```

## Связь `typeof` и `isinstance`

Имя из `typeof(x)` **часто** можно передать во второй аргумент `isinstance`, но это не всегда одно и то же правило (например, для чисел `typeof(3)` — `"int"`, а `isinstance(3, "number")` тоже `true`). Для строк `"date"` / `"money"` `isinstance` смотрит на **содержимое** строки, а не только на `typeof`.

Если сомневаетесь, выведите отладочно:

```dc
print("typeof =", typeof(x))
print("same as isinstance =", isinstance(x, typeof(x)))

```

Для многих типов второй вызов даст `true`, но для чисел и строк с подтипами возможны исключения — ориентируйтесь на таблицу выше.
