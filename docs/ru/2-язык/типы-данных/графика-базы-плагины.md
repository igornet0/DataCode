# Окно, изображение, график, база данных, плагины

Эти типы появляются, когда вы подключаете **графику**, **БД** или **нативные модули**. У каждого свой набор операций; часть доступна через **`["имя"]`**, часть — только через вызовы API модуля.

Проверка типа строкой: **`isinstance(x, "window")`**, **`"image"`**, … — полный список в [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Окно (`window`)

Дескриптор окна интерфейса. Индексация **`window["что-то"]`** в общем случае **не** поддерживается — смотрите документацию модуля **plot** / GUI вашего проекта.

---

## Изображение (`image`)

Растровые данные. Прямой доступ через **`img["поле"]`** ограничен; значение передаётся между функциями модуля графики.

---

## Фигура (`figure`)

Объект графика. Поддерживаемое свойство:

- **`figure["axes"]`** — массив **рядов** осей; каждый ряд — массив значений типа **ось**.

---

## Ось (`axis`)

Ось на графике. Методы (строковые ключи), если загружен модуль **plot**:

- **`imshow`**, **`set_title`**, **`axis`**

Без модуля plot вы получите ошибку вроде «Plot module not found».

---

## Движок БД (`database_engine`)

Строковый ключ возвращает привязанный вызов:

- **`connect`**, **`execute`**, **`query`**, **`run`**

Точный сценарий (создание движка, строка подключения) — в документации модуля **`database`** / **`database_engine`** проекта.

---

## Кластер БД (`database_cluster`)

Для ключей **`add`**, **`get`**, **`names`** в стек попадает и кластер, и соответствующая функция — дальше вызывайте так, как описано в API модуля БД.

---

## Объект плагина (`plugin_opaque`)

«Чёрный ящик» из нативного модуля (например, тензор). **`typeof`** может вернуть имя типа из плагина.

- Если настроен **`native_plugin_call`**, выражение **`opaque[key]`** может уходить в код плагина.
- Для некоторых операций **`str(...)`**, **`sum`**, **`average`** могут вызывать плагин (см. реализацию в `basic.rs` / `array.rs`).

Проверка: **`isinstance(x, "plugin_opaque")`** или имя типа, которое возвращает плагин.

---
