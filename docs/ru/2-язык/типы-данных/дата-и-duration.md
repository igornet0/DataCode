# Дата и длительность (`date` и `duration`)

В рантайме это **отдельные** значения: момент времени (`date`) и интервал (`duration`). Не путайте их с **строковой** эвристикой `typeof` для текста в кавычках, похожего на дату — см. [строка.md](строка.md) и раздел ниже.

---

## `typeof` и `isinstance`

- Для **значения** `date(...)` / `now()`: `typeof` → `"date"`, `isinstance(x, date)` → `true`.
- Для **значения** `duration(...)`: `typeof` → `"duration"`, `isinstance(x, duration)` → `true`.
- Литерал `"2024-01-15"` в кавычках — по-прежнему **строка**; по содержимому `typeof` может вернуть `"date"` (см. [строка.md](строка.md)). Это **не** то же самое, что результат `date("2024-01-15")` — отдельное значение типа **`date`**.

---

## Получение даты

- **`now()`** — текущий момент в UTC, тип **`date`** (внутри — с фиксированным смещением 0, вывод в стиле RFC 3339).
- **`date(value)`** — разбор или нормализация:
  - уже **`date`** → тот же момент;
  - **число** — Unix-время в секундах; дробная часть задаёт доли секунды (наносекунды);
  - **строка** — если строка распознана парсером дат, иначе **`null`**.
- **`date_to_unix(value)`** — для **`date`** возвращает секунды как **число** (с дробной частью); для распознаваемой **строки-даты** — то же; для **числа** возвращает его как есть; иначе **`null`**.

Подробности по встроенным функциям: [преобразование типов](../функции/преобразование-типов.md) (`date`), [дата и время](../функции/дата-и-время.md) (`now`, `date_to_unix`, `parse_date`, `format_date`, `duration`).

## Парсинг и форматирование по шаблону

Для строк с **нестандартным** форматом (не ISO и не встроенный авто-парсер `date()`) используйте **`parse_date(string, format)`**. Шаблон — директивы [chrono strftime](https://docs.rs/chrono/latest/chrono/format/strftime/index.html) (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`, `%z`, …).

```dc
d = parse_date("15.03.2024", "%d.%m.%Y")
d = parse_date("12/10/2020", "%m/%d/%Y")
```

При несовпадении формата → **`null`** (как у `date(string)`).

**`format_date(date, format)`** — дата в строку по шаблону. Первый аргумент — значение **`date`** (или строка, которую распознаёт `date()`). Метод **`d.format(format)`** эквивалентен.

```dc
d = parse_date("15.03.2024", "%d.%m.%Y")
format_date(d, "%Y-%m-%d")   # "2024-03-15"
d.format("%d.%m.%Y")          # "15.03.2024"
```

В колонке таблицы: `data.map("SignedUp", fn(s) => parse_date(s, "%Y-%m-%d"))` или обёртка-функция с нужным форматом.

| Директива | Значение |
|-----------|----------|
| `%Y` | Год (4 цифры) |
| `%m` | Месяц 01–12 |
| `%d` | День 01–31 |
| `%H` | Час 00–23 |
| `%M` | Минута 00–59 |
| `%S` | Секунда 00–59 |
| `%z` | Смещение UTC `+0000` |

Полный список и отличия от Python — в документации chrono.

## Поля значения `date`

У значения типа **`date`** доступны **поля** (отдельных глобальных функций нет). Скобки не обязательны: **`d.year`** и **`d.year()`** дают одно и то же.

| Поле | Результат |
|------|-----------|
| `year`, `month`, `day` | Число: календарные год / месяц (1–12) / день месяца в **смещении самой даты** |
| `quarter` | Число: календарный квартал (**1..4**) в **смещении самой даты** |
| `hour`, `minute`, `second` | Число: часы (0–23), минуты и секунды (0–59) в этом же смещении |
| `weekday` | Число: день недели по ISO 8601 (**1** = понедельник … **7** = воскресенье) в календарной дате смещения даты |
| `to_utc` или `utc` | Значение **`date`**: тот же момент времени со смещением **UTC (+00:00)** |
| `format` | Метод: `d.format("%Y-%m-%d")` — см. раздел «Парсинг и форматирование» |

Если момент задан строкой с неUTC-смещением (например `+10:00`), компоненты `year` … `second` соответствуют **локальному** времени в этом смещении; после `to_utc` / `utc` календарная дата может сдвинуться относительно полуночи UTC.

```dc
d = date("2024-03-15T13:45:30Z")
print(d.year, d.month, d.day)
u = d.utc
print(typeof(u))   # date

```

## Длительность

**`duration(seconds=, minutes=, hours=, days=, milliseconds=)`** — все именованные аргументы необязательны (по умолчанию 0). Сумма задаёт интервал (включая дробные части, где уместно).

```dc
h = duration(hours=1)
print(typeof(h))   # duration

```

---

## Арифметика

- **`date + duration`** и **`duration + date`** → **`date`** (смещение вперёд).
- **`date - duration`** → **`date`** (смещение назад).
- **`date - date`** → **`duration`** (знаковая разница).

```dc
t = now()
h = duration(hours=1)
print(t + h)
print((t + h) - t)              # тот же интервал, что и h
print(date("2024-01-02") - date("2024-01-01"))

```

## Экспорт в SQLite

При выгрузке в SQLite (или записи через ORM/`database_engine`):

- **`date`** (полночь UTC) → declared `DATE`, хранение `YYYY-MM-DD`
- **`date`** со временем → metadata `datetime`, declared `DATETIME`, хранение UTC `YYYY-MM-DDTHH:MM:SS.fffZ`
- **`duration`** → declared `INTEGER` (наносекунды как `i64`)
- **Строковые ячейки**, похожие на date (`YYYY-MM-DD`), datetime (RFC3339 / ISO), int или float, определяются автоматически для DDL и `_datacode_schema`

Типы колонок также пишутся в `_datacode_schema` (вместе с `_datacode_version`). При чтении приоритет у metadata; иначе используются declared-типы из `PRAGMA table_info`. После скрипта DCP `__sql__` / `__sql_table__` `_datacode_schema` пересинхронизируется с итоговым PRAGMA (TEXT-колонки могут уточняться до `date` / `datetime` по выборке значений).
