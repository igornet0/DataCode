# Массивы, срезы и `enum(...)`

**Массив** — упорядоченный список, который можно менять (добавлять элементы, сортировать и т.д.). **Срез** (view) — «окно» в тот же массив без копирования данных. **`enum`** — обёртка для цикла с индексом.

**Синтаксис** (литералы, срезы, comprehension): [0-синтаксис/массивы](../../0-синтаксис/03-массивы.md).

Проверка типов: [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Массив

### Как создать

```dc
a = [1, 2, 3]              # литерал
b = array(10, 20)          # функция array(...)
c = range(5)               # [0,1,2,3,4]
d = array_with_capacity(100)   # пустой, но с запасом памяти

```

Ссылки на один и тот же массив ведут себя как **одна** коллекция: изменение видно везде.

### Индекс `arr[i]`

- **`i`** — целое число.
- **Отрицательный индекс** отсчитывается с конца (как в Python): `[-1]` — последний элемент.

```dc
v = [10, 20, 30]
print(v[0])       # 10
print(v[-1])      # 30

```

**Срезы** с шагом — см. [0-синтаксис/массивы](../../0-синтаксис/03-массивы.md#срезы-arrstartstopstep); под капотом используется поддержка в `array_ops.rs`.

### Методы `arr["имя"]`

Имена совпадают с **глобальными** функциями:

`push`, `pop`, `unique`, `reverse`, `sort`, `sum`, `average`, `count`, `any`, `all`, `chunk`.

Два стиля вызова эквивалентны по смыслу:

```dc
x = [1]
push(x, 2)
x.push(3)          # сначала взяли метод, потом вызвали
print(x)

```

Больше примеров: `examples/ru/03-типы данных/массивы.dc`.

### Встроенные функции

- создание: `array`, `array_with_capacity`, `range`;
- размер и агрегаты: `len`, `sum`, `average`, `count`, `min`, `max`, `unique`, `reverse`, `sort`, `any`, `all`;
- **`map`**, **`filter`**, **`reduce`** — только для массива или среза-массива (не для кортежа);
- **`enum(массив)`** — см. раздел ниже;
- **`chunk(arr, n)`** — разбить на куски длины `n`.

Агрегаты **`sum`**, **`average`**, **`unique`** также понимают **колонку таблицы** — см. [таблица.md](таблица.md).

## Представление массива (срез, `ArrayView`)

Выглядит как массив для `typeof` (**`"array"`**), но указывает на **часть** другого массива. Полезно после операций вроде `chunk` на срезе — без лишнего копирования.

Методы те же: `push`, `pop`, …, `chunk`.

---

## `enum(...)` и перечисление

**`enum(x)`** строит обёртку для цикла **`for (i, item) in enum(x)`**:

- для **массива** или **кортежа** — пары `(индекс, элемент)`;
- для **строки** — пары `(индекс, символ как строка)`.

При обращении **`e[i]`** к результату `enum` вы получаете **кортеж** из двух элементов: номер и значение.

`typeof` для этой обёртки — **`"enumerate"`**. **`len(e)`** — как длина исходной коллекции.

## Короткая шпаргалка

| Задача | Пример |
|--------|--------|
| Добавить в конец | `push(arr, x)` или `arr.push(x)` |
| Взять с конца | `pop(arr)` |
| Есть ли хоть один «истинный» | `any(arr)` |
| Все ли элементы истинные | `all(arr)` |
| Преобразовать каждый элемент | `map(arr, f)` |
