# Путь к файлу или папке (`path`)

Значение типа **path** хранит путь в файловой системе. Создаётся функцией **`path(...)`**, дальше с ним можно работать и функциями `path_*`, и **свойствами** в квадратных скобках.

`typeof` → **`"path"`**.

Проверка: `isinstance(p, "path")` — [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Свойства `p["имя"]`

Строковый ключ — имя свойства (как поле):

| Ключ | Что получите |
|------|----------------|
| `is_file` | `true` / `false` — обычный файл ли |
| `is_dir` | `true` / `false` — каталог ли |
| `exists` | существует ли путь |
| `extension` | расширение или `null` |
| `name` | имя файла / последний сегмент или `null` |
| `parent` | путь к родителю или `null` |

Пример:

```dc
p = path("./README.md")
print(p["exists"])
print(p["name"])

```

---

## Встроенные функции

**Путь:**

- `path`, `path_name`, `path_parent`, `path_exists`, `path_is_file`, `path_is_dir`, `path_extension`, `path_stem`, **`path_len`**

**Файлы и каталоги:**

- `read`, `getcwd`, `list_files`

### Важно про `len`

Для пути **`len(p)` не задаётся** — вместо этого используйте **`path_len(p)`**, если нужна длина пути в смысле реализации.

```dc
p = path("/tmp")
print(path_len(p))

```
