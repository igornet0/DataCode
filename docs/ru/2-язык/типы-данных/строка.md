# Строки

Текст в **двойных кавычках** — это строка. Один и тот же тип строки используется и для обычного текста, и (после обработки функциями) для **дат** и **денежных** подписей в строковом виде.

Проверка типов: [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Что такое `typeof` для строки

От **содержимого** зависит строка, которую вернёт `typeof`:

| Содержимое | `typeof` |
|------------|----------|
| Похоже на дату (`YYYY-MM-DD` в начале) | `"date"` |
| Есть `$`, `EUR`, `€` | `"money"` |
| Остальное | `"string"` |

Отдельных типов «Дата» или «Деньги» в машине нет — это всё те же строки, по-разному **названные** в `typeof`.

```dc
print(typeof("hello"))           # string
print(typeof("2024-01-15"))      # date
print(typeof("$10.00"))          # money

```

## Индекс: символ и методы

### Символ по номеру `s[i]`

Индекс — по **символам Unicode** (не по байтам). Отрицательные индексы **не** поддерживаются.

```dc
s = "Привет"
print(s[0])            # одна буква как строка

```

### Срез `s[start:stop:step]`

Тот же синтаксис, что у массивов (см. [массивы](../../0-синтаксис/03-массивы.md#срезы-arrstartstopstep)). Границы — по **символам Unicode** (как `s[i]`); отрицательные индексы и шаг поддерживаются.

| Запись | Смысл |
|--------|--------|
| `s[a:b]` | символы с индекса `a` до `b` **не включая** `b` |
| `s[:]` | вся строка (новая копия) |
| `s[::2]` | каждый второй символ |
| `s[::-1]` | символы в обратном порядке |

```dc
s = "Hello, World!"
print(s[1:4])     # ell
print(s[-3:])     # ld!
print(s[::2])     # Hlo,Wrd!

```

Результат — **новая строка** (не view, в отличие от среза массива). Присваивание срезу `s[a:b] = ...` **не поддерживается** — строки неизменяемы.

**Заметка:** `len(s)` возвращает длину в **байтах** UTF-8, а `s[i]` и `s[a:b]` работают по **символам**; для не-ASCII текстов эти числа могут различаться.

**Примеры:** [`examples/ru/01-основы/строки.dc`](../../../../examples/ru/01-основы/строки.dc), DP: [`examples/ru/09-продвинутые/dp/longest_palindrome_substring.dc`](../../../../examples/ru/09-продвинутые/dp/longest_palindrome_substring.dc).

### Методы через строковый ключ `s["имя"]`

Возвращается встроенная функция с тем же смыслом, что и глобальная (удобно писать `s.upper()` вместо `upper(s)` для первого аргумента):

| Свойство | Как вызвать вручную |
|----------|---------------------|
| `upper` | `upper(s)` |
| `lower` | `lower(s)` |
| `trim` | `trim(s)` |
| `split` | `split(s, разделитель)` |
| `join` | для **массива** строк: `join(массив, клей)` |
| `contains` | `contains(s, подстрока)` |
| `isupper` | `isupper(s)` |
| `islower` | `islower(s)` |
| `replace` | `replace(s, что_искать, на_что)` |
| `capitalize` | `capitalize(s)` |

Пример:

```dc
t = "  a,b,c  "
print(t.trim())
print(t.split(","))

```

## Встроенные функции

- **`str(x)`** — представление значения как строка.
- **`len(s)`** — длина (в реализации для Rust-строки это длина в **байтах** UTF-8; для не-ASCII символов число может отличаться от «числа букв»).
- **`date(...)`**, **`money(...)`** — нормализация/форматирование в строку.
- **`enum(s)`** — обход по символам в цикле `(i, ch)` — см. [массивы.md](массивы.md).

## Конструкция `str[N]` (не строка-символы)

Если индекс взять у **глобальной функции** `str` как у значения: **`str[5]`** при целом `N ≥ 0`, получится **объект-дескриптор** полей `__type`, `__length` — для типизации в стиле «строка фиксированной длины», а не обычная строка. Подробнее в [объект.md](объект.md).
