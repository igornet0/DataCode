# Функции

Значение-функция можно **сохранить в переменную**, **передать** в другую функцию или в **`map` / `filter` / `reduce`** (где это поддерживается).

`typeof` для любой функции → **`"function"`**.

Проверка: `isinstance(f, "function")` — [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Виды функций (внутри VM)

Пользователю чаще всего всё выглядит одинаково — как **вызов** `f(...)`:

- функция, объявленная в текущем файле или чанке;
- функция, **импортированная** из модуля;
- **встроенная** функция языка (`print`, `len`, …);
- функция из **нативной библиотеки** (загруженный `.dylib` / `.so`).

---

## Аргументы вызова: `*args` и `**kwargs`

Введение с примерами: [урок 06 — функции](../../0-синтаксис/06-функции.md#переменное-число-аргументов-args-и-kwargs). Пример целиком: [`06-переменные_аргументы.dc`](../../../../examples/ru/04-функции/06-переменные_аргументы.dc).

### Объявление

```dc
fn f(a, b = 2, *args, **kwargs) { ... }
```

| Правило | Ошибка при нарушении |
|---------|----------------------|
| Порядок: обычные → со значением по умолчанию → `*args` → `**kwargs` | `Regular parameters cannot follow *args or **kwargs`, `Non-default argument follows default argument` |
| Не больше одного `*args` и одного `**kwargs` | `Only one *args parameter allowed`, `Only one **kwargs parameter allowed` |
| `*args` раньше `**kwargs`, `**kwargs` — последний | `*args must appear before **kwargs`, `**kwargs must be the last parameter` |
| У `*args` / `**kwargs` нет значения по умолчанию | `*args and **kwargs cannot have default values` |

Внутри функции `args` — **массив** (`typeof` → `"array"`), `kwargs` — **объект** (`typeof` → `"object"`). Если лишних аргументов нет — `[]` и `{}`.

### Как аргументы связываются с параметрами

1. Именованные аргументы (`имя = значение`) попадают в параметры с тем же именем.
2. Позиционные аргументы по порядку заполняют первые обычные параметры. Если такой параметр уже получил значение по имени — ошибка `got multiple values for argument '<имя>'`.
3. Позиционные аргументы, которым не хватило обычных параметров, попадают в `*args`. Без `*args` — ошибка «слишком много позиционных аргументов».
4. Незаполненные параметры берут значение по умолчанию. Если его нет — `missing required argument '<имя>'`.
5. Именованные аргументы без подходящего параметра попадают в `**kwargs`. Без `**kwargs` — `got an unexpected keyword argument '<имя>'`.

```dc
fn f(a, b = 2, *args, **kwargs) {
    return [a, b, args, kwargs]
}

print(f(1))                  # [1, 2, [], {}]
print(f(1, 5, 6, 7))         # [1, 5, [6, 7], {}]
print(f(1, x = 9))           # [1, 2, [], {x: 9}]
print(f(b = 8, a = 0))       # [0, 8, [], {}]
```

### Распаковка при вызове

| Запись | Требование к значению | Результат |
|--------|----------------------|-----------|
| `f(*arr)` | массив | элементы становятся позиционными аргументами |
| `f(**obj)` | объект со строковыми ключами | пары становятся именованными аргументами |

- Распаковок может быть несколько: `f(*a, *b)` — сначала элементы `a`, потом `b`.
- Порядок в вызове: позиционные → `*массив` → именованные и `**объект` (их можно смешивать). Позиционный аргумент после `*` — ошибка `Positional argument follows * unpacking`, `*` после именованного — `* unpacking must appear before named arguments`.
- Ключ, переданный дважды (`f(a = 1, **{"a": 2})`), — ошибка `got multiple values for argument 'a'`.
- Не массив после `*` — `* unpacking requires an array`; не объект после `**` — `** unpacking requires an object with string keys`.

### Что получает функция

- `args` и `kwargs` — **новые** массив и объект. Изменения внутри функции (`push(args, x)`, `kwargs["k"] = v`) не затрагивают массив или объект, переданный через `*` / `**`.
- Порядок ключей в `kwargs` **не гарантирован**. Для перебора используйте `for key in kwargs.keys { ... }`, для проверки — `"key" in kwargs`, для значения по умолчанию — `kwargs.get("key", default)`.

### Где работает

- функции текущего файла, вложенные функции, лямбды (`fn(*xs) => len(xs)`);
- функции в переменной (`g = f; g(1, b = 2)`);
- функции из модулей: `from m import f; f(1, b = 2)` и `m.f(1, *xs, b = 2)`.

Для функций текущего файла компилятор знает сигнатуру, и ошибки связывания выдаются **при компиляции**. Для функций из переменных и модулей аргументы связываются **при вызове**: ошибки возникают во время выполнения, и их можно перехватить `try` / `catch`.

### Методы и конструкторы

`*args` / `**kwargs` работают и в методах, и в конструкторах классов (в том числе вместе с `@class`):

```datacode
cls Bag {
    public:
    n: int
    new Bag(*items, **opts) {
        this.n = len(items)
    }
    fn add(*xs) {
        return len(xs)
    }
}

Bag(1, 2, mode = "x").n   # 2
Bag(*[1, 2, 3]).n         # 3
```

Выбор конструктора: сначала перегрузка с точным числом аргументов (`new Bag(a)`), затем перегрузка с `*args`, у которой больше всего обычных параметров. `super(...)` и `: this(...)` выбирают конструктор с `*args` так же.

### Аннотации типов

Аннотация у `*args` / `**kwargs` проверяется для **каждого элемента**: `fn f(*nums: int)` при вызове `f(1, "x")` даёт ошибку `Argument 'nums[1]' expected type 'int', got 'str'`.

### Ограничения

- Встроенные функции и функции нативных плагинов принимают именованные аргументы только там, где это описано в их документации.

---

## Индексация `f[...]`

Обычно к функции **нельзя** обращаться как к массиву.

**Исключение:** глобальная **`str`** — это тоже вызываемое значение; запись **`str[N]`** при целом **`N ≥ 0`** создаёт **объект-дескриптор** длины строки (см. [строка.md](строка.md)).

## Где функции используются

```dc
fn double(x) {
    return x * 2
}
f = double
print(f(21))

a = [1, 2, 3]
print(map(a, double))

```

Список имён встроенных глобальных функций задаётся константой **`BUILTIN_GLOBAL_NAMES`** в `src/vm/globals.rs`. После них в рантайме могут добавляться нативы из плагинов.

---

## Ограничение

В **`map` / `filter` / `reduce`** колбэком **нельзя** использовать функцию **другого модуля** в некоторых режимах (сообщение об ошибке вида «module functions as callback are not supported») — см. `higher_order.rs`. Локальные функции и встроенные нативы там работают.
