# Числа, логика (`bool`), `null`, многоточие (`...`)

## Числа (`int` и `float`)

В программе вы пишете числа как обычно: `42`, `-1`, `3.14`. Поддерживается **экспоненциальная запись**: `1e-9`, `2.5E+10`, `6e3` (как в Python). Внутри виртуальная машина хранит их как одно число с плавающей точкой, но **`typeof`** различает целые и дробные:

- без дробной части → **`"int"`**;
- с дробной → **`"float"`**.

### Примеры

```dc
print(typeof(7))        # int
print(typeof(7.0))      # int (дробная часть нулевая)
print(typeof(0.5))      # float
print(10 + 3 * 2)       # арифметика как ожидается

```

### Побитовые операции

Только для **`int`**: `&`, `|`, `^`, `~`, `<<`, `>>`. Подробнее — [побитовые операторы](../../0-синтаксис/10-побитовые-операторы.md).

```dc
print(5 & 3)      # 1
print(1 << 10)    # 1024
```

```

### Полезные функции

| Функция | Назначение |
|---------|------------|
| `int(x)` | Целая часть / разбор из строки |
| `float(x)` | Число с плавающей точкой |
| `abs`, `sqrt`, `pow`, `min`, `max`, `round` | Математика |

Проверка типа: `isinstance(x, "int")`, `isinstance(x, "float")` — см. [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Булевы значения (`bool`)

Только **`true`** и **`false`**. В условиях `if`, `while` используется **истинность** значения (см. ниже).

```dc
print(typeof(true))     # bool
print(isinstance(false, "bool"))   # true

```

---

## `null`

Означает «значения нет». В условиях **`null` — ложь**.

```dc
x = null
print(typeof(x))        # null
print(isinstance(x, "null"))       # true

```

---

## Многоточие `...` (`ellipsis`)

Литерал **`...`** — служебное значение (например, в метаданных полей). В обычных скриптах встречается редко.

`typeof` → `"ellipsis"`.

---

## Индексация `x["имя"]`

У чисел, `bool`, `null` и `...` **нет** свойств в квадратных скобках — только операторы и функции.

---

## Что считается «истиной» в условиях

Удобно помнить для `if x { ... }`:

- **ложь:** `null`, `false`, число **0**, **пустая** строка, **пустой** массив или срез, пустая таблица, пустой объект;
- **истина:** ненулевое число, непустая строка, непустые коллекции, `true`, большинство объектов среды (окна, движки БД и т.д.).

Точные правила заданы в `is_truthy` в `src/common/value.rs`.
