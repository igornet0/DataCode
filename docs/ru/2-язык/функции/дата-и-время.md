# Дата и время

← [Встроенные функции](./README.md)

Функции для текущего момента, интервалов и Unix-времени. Преобразование строки в дату — [`date()`](./преобразование-типов.md#datevalue).

**📚 Подробнее о типах:** [дата и duration](../типы-данных/дата-и-duration.md)

### `now()`

Текущая дата и время (UTC).

**Аргументы:** нет

**Возвращает:** `date`

**Примеры:**
```datacode
now()
typeof(now())   # "date"
```

---

### `date_to_unix(value)`

Unix-время в **секундах** (дробная часть — наносекунды).

**Аргументы:**
- `value` (date | string | number) — дата, ISO-строка или уже готовое Unix-число

**Возвращает:** `number`, или `null`

**Примеры:**
```datacode
date_to_unix(now())
date_to_unix("2024-01-15T10:30:00Z")
```

---

### `parse_date(string, format)`

Разбор строки в **`date`** по явному шаблону chrono/strftime (`%Y`, `%m`, `%d`, …).

**Аргументы:** `string`, `format` (оба string)

**Возвращает:** `date` или `null`

**Примеры:**
```datacode
parse_date("15.03.2024", "%d.%m.%Y")
parse_date("12/10/2020", "%m/%d/%Y")
```

---

### `format_date(date, format)`

Форматирование **`date`** в строку. Эквивалент `d.format(format)`.

**Аргументы:** `date` (или распознаваемая строка), `format` (string)

**Возвращает:** `string`

**Примеры:**
```datacode
d = parse_date("15.03.2024", "%d.%m.%Y")
format_date(d, "%Y-%m-%d")
d.format("%d.%m.%Y")
```

---

### `duration(seconds, minutes, hours, days, milliseconds)`

Создаёт значение типа `duration` как сумму компонент (все аргументы опциональны, по умолчанию 0).

**Аргументы:**
- `seconds`, `minutes`, `hours`, `days`, `milliseconds` (number)

**Возвращает:** `duration`

**Примеры:**
```datacode
duration(seconds=30)
duration(minutes=5, seconds=30)
duration(hours=1)
```
