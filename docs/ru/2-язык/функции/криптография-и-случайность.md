# Криптография и случайность

← [Встроенные функции](./README.md)

Хеширование (SHA-2, HMAC) и генерация случайных данных. **Не предназначено для хранения паролей** — для паролей используйте модуль [`crypto`](../модули/crypto/README.md) (`Argon2`, `bcrypt`).

**📚 Тесты:** `tests/crypto_tests.rs`

### `sha256(data)`

Вычисляет SHA-256 от строки или байтов.

**Аргументы:**
- `data` (string | bytes) — входные данные

**Возвращает:** `bytes` длиной 32, или `null` при ошибке типа

**Отображение:** `typeof` → `"bytes"`; `str(sha256(...))` → lowercase hex (64 символа). Данные остаются бинарными — индекс `d[i]`, `len(d)`, `hmac_*` работают как раньше.

**Примеры:**
```datacode
len(sha256(""))       # 32
str(sha256("hello"))  # 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
print(sha256("hello"))
```

---

### `sha512(data)`

Аналогично `sha256`, но SHA-512 (64 байта результата). `str(...)` — hex из 128 символов.

---

### `hmac_sha256(key, data)`

HMAC-SHA256. Оба аргумента должны быть **bytes** (не строки).

**Аргументы:**
- `key` (bytes)
- `data` (bytes)

**Возвращает:** `bytes` (32 байта), или `null`. `str(...)` — hex digest.

**Примеры:**
```datacode
key = random_bytes(16)
data = random_bytes(8)
hmac_sha256(key, data)
```

---

### `hmac_sha512(key, data)`

HMAC-SHA512; оба аргумента — `bytes`, результат 64 байта. `str(...)` — hex digest.

---

### `random_bytes(size)`

Криптографически стойкие случайные байты из OS RNG.

**Аргументы:**
- `size` (int) — неотрицательное целое; максимум 1 048 576 (1 MiB)

**Возвращает:** `bytes`, или ошибка при превышении лимита / неверном типе

**Отображение:** `typeof` → `"bytes"`; `str(...)` → `"<bytes len=N>"` (не hex).

**Примеры:**
```datacode
random_bytes(16)
```

---

### `random()`

Случайное **вещественное** число в полуинтервале **[0, 1)** — 0 включительно, 1 исключён (как в Python `random.random()`). Использует тот же псевдослучайный генератор потока, что `random_int` и `random_seed`.

**Аргументы:** нет

**Возвращает:** `float` (`number`)

**Примеры:**
```datacode
x = random()
random_seed(42)
a = random()
random_seed(42)
b = random()
# a == b
```

---

### `random_int(min, max)`

Случайное **целое** в диапазоне `[min, max]` включительно (псевдослучайный генератор потока, см. `random_seed`).

**Аргументы:**
- `min` (int)
- `max` (int), `min <= max`

**Возвращает:** `number` (целое), или `null` при ошибке

**Примеры:**
```datacode
random_int(1, 6)          # «кубик»
random_int(0, 100)
```

---

### `random_seed(seed)`

Фиксирует seed псевдослучайного генератора **в текущем потоке** (для воспроизводимых последовательностей `random`, `random_int`).

**Аргументы:**
- `seed` (int) — неотрицательное целое

**Возвращает:** `null`

**Примеры:**
```datacode
random_seed(42)
a = random_int(0, 999999)
random_seed(42)
b = random_int(0, 999999)
# a == b
```
