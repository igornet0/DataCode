### `push(array, item)`

Добавляет элемент в конец массива (изменяет исходный массив).

**Аргументы:**
- `array` (array) - массив для изменения
- `item` (any) - элемент для добавления

**Возвращает:** `array` - тот же массив (для цепочки вызовов)

**Примеры:**
```datacode
arr = [1, 2, 3]
push(arr, 4)        # arr теперь [1, 2, 3, 4]
push(arr, "hello")  # arr теперь [1, 2, 3, 4, "hello"]

```

---

### `pop(array)`

Удаляет и возвращает последний элемент массива.

**Аргументы:**
- `array` (array) - массив для изменения

**Возвращает:** `any` - последний элемент массива, или `null` если массив пуст или аргумент не массив

**Примеры:**
```datacode
arr = [1, 2, 3]
pop(arr)     # возвращает 3, arr теперь [1, 2]
pop(arr)     # возвращает 2, arr теперь [1]
pop([])      # null

```

---

### `unique(array)`

Возвращает новый массив с уникальными элементами (сохраняет порядок первого вхождения).

**Аргументы:**
- `array` (array) - массив для обработки

**Возвращает:** `array` - новый массив с уникальными элементами, или `null` если аргумент не массив

**Примеры:**
```datacode
unique([1, 2, 2, 3, 1])        # [1, 2, 3]
unique(["a", "b", "a", "c"])   # ["a", "b", "c"]

```

---

### `reverse(array)`

Обращает порядок элементов в массиве (изменяет исходный массив).

**Аргументы:**
- `array` (array) - массив для изменения

**Возвращает:** `array` - тот же массив с обращенным порядком элементов

**Примеры:**
```datacode
arr = [1, 2, 3]
reverse(arr)  # arr теперь [3, 2, 1]

```

---

### `sort(array)`

Сортирует элементы массива по строковому представлению (изменяет исходный массив).

**Аргументы:**
- `array` (array) - массив для сортировки

**Возвращает:** `array` - отсортированный массив

**Примеры:**
```datacode
arr = [3, 1, 2]
sort(arr)  # arr теперь [1, 2, 3]

arr2 = ["c", "a", "b"]
sort(arr2)  # arr2 теперь ["a", "b", "c"]

```

---

### `sum(array)`

Вычисляет сумму всех чисел в массиве.

**Аргументы:**
- `array` (array) - массив чисел

**Возвращает:** `number` - сумма чисел, или `0` если чисел нет или аргумент не массив

**Примеры:**
```datacode
sum([1, 2, 3])        # 6
sum([10, 20, 30])     # 60
sum([1.5, 2.5, 3.0])  # 7.0

```

---

### `average(array)`

Вычисляет среднее арифметическое чисел в массиве.

**Аргументы:**
- `array` (array) - массив чисел

**Возвращает:** `number` - среднее значение, или `0` если чисел нет или аргумент не массив

**Примеры:**
```datacode
average([1, 2, 3])        # 2.0
average([10, 20, 30])     # 20.0
average([1.5, 2.5, 3.0])  # 2.3333333333333335

```

---

### `count(array)`

Возвращает количество элементов в массиве.

**Аргументы:**
- `array` (array) - массив

**Возвращает:** `number` - количество элементов, или `0` если аргумент не массив

**Примеры:**
```datacode
count([1, 2, 3])      # 3
count([])             # 0
count(["a", "b"])     # 2

```

---

### `map(collection, fn | native)`

Преобразует каждый элемент массива (или представления массива) и возвращает **новый массив той же длины**.

- `fn(x) => ...` — один аргумент на элемент.
- `fn(x, i) => ...` — значение и числовой индекс `i` (с нуля).
- `str` (или любой **одноаргументный** встроенный вызов) — применяется к каждому элементу.

**Возвращает:** `array` или ошибку при сбое колбэка.

---

### `filter(collection, predicate)`

Оставляет элементы по порядку, где предикат истинен (truthy). **Только пользовательские функции** (не сырой натив).

- `fn(x) => ...` или `fn(x, i) => ...` — те же правила arity, что у `map`.

**Возвращает:** новый `array` (длина не больше исходной).

---

### `reduce(collection, fn, initial)`

Свёртка массива с **обязательным** `initial`. У колбэка должна быть arity 2: `(acc, item)`.

`reduce([], fn, initial)` возвращает `initial` без вызова функции.

Вариант `reduce` **без** начального значения **не** поддерживается.

**Возвращает:** одно значение.

---

### `any(collection)` / `all(collection)`

- `any` — `true`, если **хотя бы один** элемент truthy.
- `all` — `true`, если **все** элементы truthy и коллекция **не пуста**.

Поддерживают массив и ленивый iterable (например результат `map`).

**Примеры:**
```datacode
any([0, false, 1])    # true
all([1, 2, 3])        # true
all([])               # false
```

---

### `enum(iterable)`

Ленивая обёртка `(index, element)` для циклов `for i, x in enum(arr)`.

**Аргументы:**
- `iterable` (array | tuple | string | table)

**Возвращает:** enumerate-iterable, или `null`

---

### `array_with_capacity(n)`

Пустой массив с заранее выделенной ёмкостью (удобно перед циклом с `push`).

**Аргументы:**
- `n` (int) — ёмкость, `0 … 1_000_000_000`

**Возвращает:** `array`

**Примеры:**
```datacode
buf = array_with_capacity(1000)
```

---

### `set()` / `set(array)`

Создаёт множество: пустое или из элементов массива (элементы должны быть hashable).

**Аргументы:**
- опционально один `array`

**Возвращает:** `set`

**Примеры:**
```datacode
s = set()
s = set([1, 2, 2, 3])   # set с уникальными элементами
```

Методы множества: `.add()`, `.remove()`, `.copy()` и др. — см. [объект](../типы-данных/объект.md).
