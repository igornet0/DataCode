### `abs(n)`

Возвращает абсолютное значение числа.

**Аргументы:**
- `n` (number) - число

**Возвращает:** `number` - абсолютное значение, или `null` если аргумент не число

**Примеры:**
```datacode
abs(-5)      # 5
abs(5)       # 5
abs(-3.14)   # 3.14

```

---

### `sqrt(n)`

Возвращает квадратный корень числа.

**Аргументы:**
- `n` (number) - число (должно быть неотрицательным)

**Возвращает:** `number` - квадратный корень, или `null` если число отрицательное или аргумент не число

**Примеры:**
```datacode
sqrt(16)     # 4.0
sqrt(9)      # 3.0
sqrt(-1)     # null

```

---

### `pow(base, exp)`

Возводит число в степень.

**Аргументы:**
- `base` (number) - основание
- `exp` (number) - показатель степени

**Возвращает:** `number` - результат возведения в степень, или `null` если аргументы не числа

**Примеры:**
```datacode
pow(2, 3)      # 8.0
pow(10, 2)     # 100.0
pow(2, 0.5)    # 1.4142135623730951 (квадратный корень из 2)

```

---

### `min(...)`

Возвращает минимальное значение из переданных чисел или из одного массива чисел (нечисловые элементы пропускаются).

**Аргументы:**
- `...` - произвольное количество чисел **или** один массив чисел

**Возвращает:** `number` - минимальное значение, или `null` если нет числовых значений (например пустой массив или только не-числа)

**Примеры:**
```datacode
min(1, 2, 3)        # 1
min(5, 2, 8, 1)     # 1
min(-5, -2, -10)    # -10
min([3, 1, 2])      # 1
min([])             # null

```

---

### `max(...)`

Возвращает максимальное значение из переданных чисел или из одного массива чисел (нечисловые элементы пропускаются).

**Аргументы:**
- `...` - произвольное количество чисел **или** один массив чисел

**Возвращает:** `number` - максимальное значение, или `null` если нет числовых значений (например пустой массив или только не-числа)

**Примеры:**
```datacode
max(1, 2, 3)        # 3
max(5, 2, 8, 1)     # 8
max(-5, -2, -10)    # -2
max([3, 1, 2])      # 3
max([])             # null

```

---

### `round(n)`

Округляет число до ближайшего целого.

**Аргументы:**
- `n` (number) - число для округления

**Возвращает:** `number` - округленное число, или `null` если аргумент не число

**Примеры:**
```datacode
round(3.5)      # 4
round(3.4)      # 3
round(-3.5)     # -3
round(-3.6)     # -4

```

---

### `ceil(n)`

Округляет число вверх до ближайшего целого.

**Аргументы:**
- `n` (number) - число

**Возвращает:** `number` - округленное вверх число, или `null` если аргумент не число

**Примеры:**
```datacode
ceil(3.1)      # 4
ceil(-3.1)     # -3
```

---

### `floor(n)`

Округляет число вниз до ближайшего целого.

**Аргументы:**
- `n` (number) - число

**Возвращает:** `number` - округленное вниз число, или `null` если аргумент не число

**Примеры:**
```datacode
floor(3.9)      # 3
floor(-3.1)     # -4
```

---

### `divmod(a, b)`

Возвращает пару `(q, r)` — частное и остаток с семантикой Python (floor division для отрицательных).

**Аргументы:**
- `a`, `b` (int | float)

**Возвращает:** кортеж из двух чисел того же «рода», или ошибка при `b == 0`

**Примеры:**
```datacode
q, r = divmod(10, 3)    # q=3, r=1
q, r = divmod(-10, 3)   # floor-семантика
```

---

### `isinf(x)`

Проверяет, является ли число бесконечностью (`±∞`).

**Аргументы:**
- `x` (int | float | number)

**Возвращает:** `bool`

**Примеры:**
```datacode
isinf(42)          # false
```
