# Преобразование типов

← [Встроенные функции](./README.md)


**📚 Примеры:** [`examples/ru/03-типы данных/`](../../../examples/ru/03-типы%20данных/)

### `int(value)`

Преобразует значение в целое число.

**Аргументы:**
- `value` (any) - значение для преобразования

**Возвращает:** `number` - целое число

**Примеры:**
```datacode
int(42.7)      # 42
int("123")     # 123
int(true)      # 1
int(false)     # 0
int(null)      # 0

```

---

### `float(value)`

Преобразует значение в дробное число.

**Аргументы:**
- `value` (any) - значение для преобразования

**Возвращает:** `number` - дробное число

**Примеры:**
```datacode
float(42)        # 42.0
float("3.14")    # 3.14
float(true)      # 1.0
float(false)     # 0.0

```

---

### `bool(value)`

Преобразует значение в булево значение.

**Аргументы:**
- `value` (any) - значение для преобразования

**Возвращает:** `bool` - булево значение

**Примеры:**
```datacode
bool(1)          # true
bool(0)          # false
bool(42)         # true
bool("")         # false
bool(null)       # false
bool([1, 2, 3])  # true
bool([])         # false

```

---

### `str(value)`

Преобразует значение в строку.

**Аргументы:**
- `value` (any) - значение для преобразования

**Возвращает:** `string` - строковое представление значения

**Примеры:**
```datacode
str(42)          # "42"
str(3.14)        # "3.14"
str(true)        # "true"
str(false)       # "false"
str(null)        # "null"
str([1, 2, 3])   # "[1, 2, 3]"

```

---

### `array(...)`

Создает массив из переданных аргументов.

**Аргументы:**
- `...` - произвольное количество значений любого типа

**Возвращает:** `array` - массив значений

**Примеры:**
```datacode
array(1, 2, 3)                    # [1, 2, 3]
array("a", "b", "c")              # ["a", "b", "c"]
array(100.50, 11, "Hello")         # [100.5, 11, "Hello"]
array([1, 3], [1, 5, 6])          # [[1, 3], [1, 5, 6]]

```

---

### `date(value)`

Преобразует значение в **`date`**.

**Аргументы:**
- `value` (`date` | string | number) — уже существующая дата, Unix-секунды или строка (ISO / встроенные форматы)

**Возвращает:** `date` или `null` (если строка не распознана)

Для произвольного формата строки используйте [`parse_date`](./дата-и-время.md#parse_datestring-format).

**Примеры:**
```datacode
typeof(date("2024-01-15T10:30:00Z"))   # "date"
date("2023-12-25").year                 # 2023
```

---

### `money(amount, format)`

Форматирует число как денежную сумму.

**Аргументы:**
- `amount` (number | string) - сумма для форматирования
- `format` (string, опционально) - строка формата (например, "$0.00", "0,0 $", "0 EUR")

**Возвращает:** `string` - отформатированная денежная сумма

**Примеры:**
```datacode
money(100.50, "$0.00")      # "$100.50"
money(250.75, "0,0 $")      # "250,75 $"
money(50, "0 EUR")          # "50 EUR"
money(100.50)               # "100.5" (без форматирования)

```
