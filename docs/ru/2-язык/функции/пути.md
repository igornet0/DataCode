### `path(string)`

Создает объект пути из строки.

**Аргументы:**
- `string` (string) - строка с путем к файлу или директории

**Возвращает:** `path` - объект пути

**Примеры:**
```datacode
path("data.csv")
path("/home/user/file.txt")
path("folder/subfolder")

```

---

### `path_name(path)`

Возвращает имя файла или директории из пути.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `string` - имя файла или директории

**Примеры:**
```datacode
path_name(path("data.csv"))           # "data.csv"
path_name(path("/home/user/file.txt")) # "file.txt"

```

---

### `path_parent(path)`

Возвращает родительский путь.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `path` - родительский путь, или `null` если родителя нет

**Примеры:**
```datacode
path_parent(path("folder/file.txt"))  # path("folder")
path_parent(path("/home/user"))       # path("/home")

```

---

### `path_exists(path)`

Проверяет существование файла или директории.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `bool` - `true` если путь существует, иначе `false`

**Примеры:**
```datacode
path_exists(path("data.csv"))
path_exists(path("/nonexistent"))

```

---

### `path_is_file(path)`

Проверяет, является ли путь файлом.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `bool` - `true` если путь указывает на файл, иначе `false`

**Примеры:**
```datacode
path_is_file(path("data.csv"))
path_is_file(path("folder"))  # false

```

---

### `path_is_dir(path)`

Проверяет, является ли путь директорией.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `bool` - `true` если путь указывает на директорию, иначе `false`

**Примеры:**
```datacode
path_is_dir(path("folder"))
path_is_dir(path("file.txt"))  # false

```

---

### `path_extension(path)`

Возвращает расширение файла.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `string` - расширение файла (без точки), или пустую строку

**Примеры:**
```datacode
path_extension(path("data.csv"))    # "csv"
path_extension(path("file.txt"))    # "txt"
path_extension(path("folder"))     # ""

```

---

### `path_stem(path)`

Возвращает имя файла без расширения.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `string` - имя файла без расширения

**Примеры:**
```datacode
path_stem(path("data.csv"))    # "data"
path_stem(path("file.txt"))    # "file"

```

---

### `path_len(path)`

Возвращает длину строкового представления пути.

**Аргументы:**
- `path` (path) - объект пути

**Возвращает:** `number` - длина пути в символах

**Примеры:**
```datacode
path_len(path("data.csv"))     # 8
path_len(path("folder/file"))  # 12

```

---

### `getcwd()`

Текущая рабочая директория процесса.

**Возвращает:** `path` (в режиме `--use-ve` может возвращаться пустой путь)

---

### `list_files(path, regex?)`

Рекурсивный обход директории; возвращает массив путей к файлам и подпапкам.

**Аргументы:**
- `path` (path | string)
- `regex` (string, опционально) — glob (`*.csv`) или regex для фильтра имён

**Возвращает:** `array` of `path`

**Примеры:**
```datacode
list_files(path("./data"))
list_files(path("./data"), "*.csv")
```

Поддерживает локальные пути и `lib://` (SMB).

---

### `archive(path)`

Открывает архив и возвращает объект `archive`. Формат определяется по magic bytes (ZIP, 7Z, RAR).

**Аргументы:**
- `path` (path | string) — путь к файлу архива

**Возвращает:** `archive`

**Пример:**
```datacode
zip = archive("./backup.zip")
print(zip.format)
print(zip.count)
data = zip.read("config/settings.json")
text = zip.read_text("README.md")
zip.extract("./output")
zip.close()
```

Подробнее: [тип archive](../типы-данных/archive.md)
