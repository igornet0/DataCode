### `upper(str)`

Преобразует строку в верхний регистр.

**Аргументы:**
- `str` (string) - строка для преобразования

**Возвращает:** `string` - строка в верхнем регистре, или `null` если аргумент не строка

**Примеры:**
```datacode
upper("hello")      # "HELLO"
upper("Hello World") # "HELLO WORLD"

```

---

### `lower(str)`

Преобразует строку в нижний регистр.

**Аргументы:**
- `str` (string) - строка для преобразования

**Возвращает:** `string` - строка в нижнем регистре, или `null` если аргумент не строка

**Примеры:**
```datacode
lower("HELLO")      # "hello"
lower("Hello World") # "hello world"

```

---

### `trim(str)`

Удаляет пробелы в начале и конце строки.

**Аргументы:**
- `str` (string) - строка для обработки

**Возвращает:** `string` - строка без пробелов в начале и конце, или `null` если аргумент не строка

**Примеры:**
```datacode
trim("  hello  ")      # "hello"
trim("  test  world  ") # "test  world"

```

---

### `split(str, delim)`

Разделяет строку по указанному разделителю.

**Аргументы:**
- `str` (string) - строка для разделения
- `delim` (string) - разделитель

**Возвращает:** `array` - массив строк, или `null` если аргументы не строки

**Примеры:**
```datacode
split("a,b,c", ",")           # ["a", "b", "c"]
split("one two three", " ")   # ["one", "two", "three"]
split("hello", "")            # ["h", "e", "l", "l", "o"]

```

---

### `join(array, delim)`

Объединяет элементы массива в строку с указанным разделителем.

**Аргументы:**
- `array` (array) - массив значений
- `delim` (string) - разделитель

**Возвращает:** `string` - объединенная строка, или `null` если аргументы неверного типа

**Примеры:**
```datacode
join(["a", "b", "c"], ",")        # "a,b,c"
join([1, 2, 3], " - ")            # "1 - 2 - 3"
join(["hello", "world"], " ")     # "hello world"

```

---

### `contains(str, substr)`

Проверяет, содержит ли строка подстроку.

**Аргументы:**
- `str` (string) - строка для поиска
- `substr` (string) - подстрока для поиска

**Возвращает:** `bool` - `true` если строка содержит подстроку, иначе `false`

**Примеры:**
```datacode
contains("hello world", "world")  # true
contains("hello world", "test")   # false
contains("hello", "lo")           # true

```

---

### `starts_with(str, prefix)`

Проверяет, начинается ли строка с указанного префикса.

**Аргументы:**
- `str` (string) - строка для проверки
- `prefix` (string) - префикс

**Возвращает:** `bool`

**Примеры:**
```datacode
starts_with("hello", "he")   # true
starts_with("hello", "lo")   # false
```

---

### `ends_with(str, suffix)`

Проверяет, заканчивается ли строка указанным суффиксом.

**Аргументы:**
- `str` (string) - строка для проверки
- `suffix` (string) - суффикс

**Возвращает:** `bool`

**Примеры:**
```datacode
ends_with("hello", "lo")   # true
ends_with("hello", "he")   # false
```

---

### `isupper(str)` / `islower(str)`

Проверяют, состоит ли строка только из символов верхнего / нижнего регистра (как в Python).

**Аргументы:**
- `str` (string)

**Возвращает:** `bool`, или `null` если аргумент не строка

**Примеры:**
```datacode
isupper("HELLO")   # true
islower("hello")   # true
isupper("Hello")   # false
```

---

### `replace(str, find, replacement)`

Заменяет **все** вхождения подстроки `find` на `replacement` (как `str.replace` в Python).

**Аргументы:**
- `str` (string) — исходная строка
- `find` (string) — что заменить
- `replacement` (string) — на что заменить

**Возвращает:** `string`, или `null` если аргументы не строки

**Примеры:**
```datacode
replace("foo-old-bar-old", "old", "new")   # "foo-new-bar-new"
"tag-old".replace("old", "archive")        # "tag-archive"
```

---

### `capitalize(str)`

Первая буква строки — в верхнем регистре, остальные — в нижнем (как `str.capitalize` в Python).

**Аргументы:**
- `str` (string)

**Возвращает:** `string`, или `null` если аргумент не строка

**Примеры:**
```datacode
capitalize("hello WORLD")   # "Hello world"
"tag".capitalize()          # "Tag"
```

---

### `ord(ch)`

Возвращает числовой Unicode code point одного символа (как `ord()` в Python).

**Аргументы:**
- `ch` (string) — строка, содержащая ровно один Unicode-символ

**Возвращает:** `int` — code point (не байт UTF-8)

**Примеры:**
```datacode
ord("A")    # 65
ord("a")    # 97
ord("Я")    # 1071
ord("中")   # 20013
ord("😀")   # 128512
```

**Ошибки:**
- `TypeError` — неверное число аргументов, пустая строка или больше одного символа
- `RuntimeError` — аргумент не строка (`ord(123)`, `ord(true)`, …)
