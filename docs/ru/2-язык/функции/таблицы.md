### `table(data, headers)`

Создает таблицу из данных и заголовков.

**Аргументы:**
- `data` (array) - массив массивов, где каждый внутренний массив представляет строку
- `headers` (array, опционально) - массив строк с названиями колонок

**Возвращает:** `table` - объект таблицы, или `null` если аргументы неверного типа

**Примеры:**
```datacode
table([[1, "a"], [2, "b"]], ["ID", "Name"])
table([[1, 2, 3], [4, 5, 6]])  # Без заголовков

```

### `read(path)` / `read(path, header_row)` / `read(path, sheet_name="sheet_name")` / `read(path, header_row, sheet_name)` / `read(path, header_row, sheet_name, header)` / `read(path, header_row, headerT=...)`

Читает файл и возвращает таблицу (для CSV/XLSX) или строку (для TXT).

**Аргументы:**
- `path` (path | string) - путь к файлу
- `header_row` (number, опционально) - номер строки с заголовками (0-based, по умолчанию 0). При `headerT` применяется к **транспонированной** таблице
- `sheet_name` (string, опционально) - имя листа для XLSX файлов (по умолчанию первый лист)
- `header` (array | object, опционально) - фильтр колонок или переименование обычной таблицы
- `headerT` (array | object, опционально) - то же, что `header`, но для транспонированной таблицы. Нельзя использовать вместе с `header`

**Возвращает:** 
- `table` - для CSV и XLSX файлов
- `string` - для TXT файлов
- `null` - если файл не найден или произошла ошибка

**Примеры:**
```datacode
read("data.csv")
read("report.xlsx", "Sales")
read("data.csv", 2)
read(path("report.xlsx"), 1, "DataSheet")
read(path("notes.txt"))  # Возвращает строку

# Загрузка только указанных колонок
sample_table = read(path("sample.csv"), header_row=0, header=["Name", "Age", "City", "Salary"])

# Переименование колонок при загрузке
sample_table = read(path("sample.csv"), header_row=0, header={"Name": "Name_A", "Age": null, "City": null, "Salary": null})

# Комбинация с sheet_name для XLSX
data = read(path("report.xlsx"), header_row=1, sheet_name="Data", header=["ID", "Value"])

# Широкий формат → таблица после транспонирования
metrics = read(path("wide.csv"), header_row=0, headerT=["Metric", "Revenue", "Cost"])

```

**Примечания:**
- Для CSV файлов автоматически определяется тип данных
- Для XLSX файлов можно указать конкретный лист
- Для XLSX файлов можно указать строку с заголовками (если она не первая)
- Порядок аргументов: `read(path, header_row, sheet_name, header, headerT)`
- Когда `header` - массив, загружаются только указанные колонки (несуществующие колонки игнорируются)
- Когда `header` - словарь, колонки переименовываются согласно соответствию (колонки, не указанные в словаре, сохраняют оригинальные имена)
- `header` и `headerT` взаимоисключающие
- При `headerT` параметр `header_row` относится к транспонированной таблице

### `table_info(table)`

Возвращает информацию о таблице (количество строк, колонок, типы данных).

**Аргументы:**
- `table` (table) - таблица

**Возвращает:** `string` - строка с информацией о таблице

**Примеры:**
```datacode
data = read(path("data.csv"))
print(table_info(data))

```

### `table_head(table, n)`

Возвращает первые n строк таблицы.

**Аргументы:**
- `table` (table) - таблица
- `n` (number, опционально) - количество строк (по умолчанию 5)

**Возвращает:** `table` - новая таблица с первыми n строками, или `null` если аргумент не таблица

**Примеры:**
```datacode
table_head(data)      # Первые 5 строк
table_head(data, 10)  # Первые 10 строк

```

---

### `table_tail(table, n)`

Возвращает последние n строк таблицы.

**Аргументы:**
- `table` (table) - таблица
- `n` (number, опционально) - количество строк (по умолчанию 5)

**Возвращает:** `table` - новая таблица с последними n строками, или `null` если аргумент не таблица

**Примеры:**
```datacode
table_tail(data)      # Последние 5 строк
table_tail(data, 10)  # Последние 10 строк

```

### `table_select(table, columns)`

Выбирает указанные колонки из таблицы.

**Аргументы:**
- `table` (table) - таблица
- `columns` (array) - массив строк с названиями колонок для выбора

**Возвращает:** `table` - новая таблица только с выбранными колонками, или `null` если колонка не найдена или аргументы неверного типа

**Примеры:**
```datacode
table_select(data, ["Name", "Age"])
table_select(data, ["ID"])
data.select(["Name", "Age"])

```

**Метод:** `data.select(columns)` — то же, что `table_select`.

### `table_rename(table, mapping)` / `table_rename(table, old, new)`

Переименовывает колонки таблицы.

**Аргументы:**
- `table` (table)
- `mapping` (object) — словарь `{старое: новое}`; `null` в значении = оставить имя
- **или** `old` (string), `new` (string) — переименовать одну колонку

**Возвращает:** `table` — новая таблица (исходная не изменяется)

**Примеры:**
```datacode
table_rename(data, {"Name": "EmployeeName", "Age": null})
table_rename(data, "Name", "EmployeeName")
data.rename("Name", "EmployeeName")
```

**Ошибки:** `KeyError` если колонка не найдена; `TypeError` при неверных типах.

### `table_drop_column(table, column)`

Удаляет одну или несколько колонок.

**Аргументы:**
- `table` (table)
- `column` (string | array[string])

**Возвращает:** `table` — новая таблица без указанных колонок

**Примеры:**
```datacode
table_drop_column(data, "Notes")
table_drop_column(data, ["Notes", "Temp"])
data.drop_column("Notes")
```

**Ошибки:** `KeyError` если колонка не найдена; `ValueError` если удаляются все колонки.

---

### `table_add_column(table, name, value?)`

Добавляет колонку в конец таблицы.

**Аргументы:**
- `table` (table)
- `name` (string) — имя новой колонки
- `value` (any, опционально) — скаляр (одно значение на все строки) или `array` (по одному значению на строку). Без аргумента — `null`.

**Возвращает:** `table` — новая таблица с добавленной колонкой

**Примеры:**
```datacode
table_add_column(data, "Region", "EMEA")
table_add_column(data, "RowNum", [1, 2, 3])
data.add_column("Region", "EMEA")
data.add_column("Extra")   # null во всех строках
```

**Ошибки:** `ValueError` если колонка уже существует или длина массива не совпадает с числом строк.

### `.map(function)` на колонке — преобразование в массив

Применяет функцию к каждой ячейке **ссылки на колонку** и возвращает материализованный **`array`** (той же длины, что колонка). В отличие от `table.map(column, fn)`, не возвращает таблицу — только значения.

**Receiver:** `table["ColumnName"]` (column reference)

**Аргументы:**
- `function` (callable) — `fn(v) => ...` или одноаргументный builtin (`int`, `round`, …)

**Возвращает:** `array`

**Примеры:**
```datacode
vat = orders["Amount"].map(fn(v) => v * 1.2)
doubled = data["Age"].map(fn(x) => x * 2)
```

**Примечание:** глобальный `map(orders["Amount"], fn)` возвращает ленивый **iterable**; для `array` используйте `array(map(...))` или `.map(fn)` на колонке.

---

### `.map(function)` на нескольких колонках — формула из нескольких полей

`table[["col1", "col2", ...]]` — **ссылка на набор колонок** (`typeof` → `"columns"`), не подтаблица. Для проекции таблицы используйте `.select(["col1", "col2"])`.

`.map(fn)` зипует названные колонки по строкам и вызывает `fn` с одним аргументом на колонку. Арность `fn` должна совпадать с числом колонок. Возвращает материализованный **`array`**.

**Receiver:** `table[["col1", "col2", ...]]` (не меньше двух имён)

**Аргументы:**
- `function` (callable) — `fn(v1, v2, ...) => ...` с арностью, равной числу колонок

**Возвращает:** `array`

**Примеры:**
```datacode
orders!["avg_check"] = orders[["total", "quantity"]].map(fn(v, q) => v / q)

# ленивый iterable (та же семантика zip)
checks = array(map(orders[["total", "quantity"]], fn(v, q) => v / q))
```

**Ошибки:**
- `TypeError` — меньше двух имён (`table[["col"]]`), не-строковые имена, или несовпадение арности callback
- `KeyError` — указанной колонки нет в таблице

---

### Присваивание колонки через `!` — `orders!["new_col"] = ...`

Postfix `!` после переменной-таблицы — контекст **записи колонки**. Присваивание добавляет колонку в конец (как `add_column`) и обновляет переменную.

**Синтаксис:**
```datacode
orders!["amount_vat"] = orders["amount"].map(fn(v) => v * 1.2)
orders!.region = ["EMEA", "APAC", "EMEA"]
```

**Правила (v1):**
- Только **присваивание** (`=`); чтение `orders!["col"]` без `=` — ошибка.
- Таблица слева — **простая переменная** (не выражение).
- Если колонка уже есть — `ValueError`.
- RHS: `array`, скаляр или результат `column.map(fn)` / `columns.map(fn)`.

**Сравнение:**
| Выражение | Результат |
|-----------|-----------|
| `orders["amount"].map(fn)` | `array` преобразованных значений |
| `orders[["a","b"]].map(fn)` | `array` из построчного zip колонок |
| `orders!["vat"] = ...` | таблица с новой колонкой в конце |
| `orders.map("amount", fn)` | таблица с **изменённой** существующей колонкой |

### `table_map(table, column, function)` / `table.map(column, function)`

Применяет функцию к каждой ячейке указанной колонки и возвращает **новую таблицу** с преобразованными значениями в этой колонке (остальные колонки без изменений).

**Аргументы:**
- `table` (table)
- `column` (string) — имя колонки
- `function` (callable) — встроенная функция (`int`, `float`, `str`, `bool`, `round`, …) или пользовательская `fn` с arity 1

**Возвращает:** `table` — новая таблица

**Примеры:**
```datacode
table_map(data, "Age", int)
table_map(data, "Amount", float)
data.map("Salary", str)
data.map("Active", to_bool_flag)

fn to_bool_flag(s) {
    if s == "yes" { return true }
    if s == "no" { return false }
    return bool(s)
}
typed = employees.map("Age", int)
```

**Ошибки:** `KeyError` если колонка не найдена; `TypeError` если третий аргумент не callable или у пользовательской функции arity ≠ 1.

**Примечание:** глобальный `map(collection, fn)` для таблиц итерирует **строки**, а не колонки. Для преобразования колонки используйте `table.map(column, fn)`.

### `table_split_column(table, column, iter_fn | delimiter, new_columns)` / `table.split_column(...)`

Разбивает одну колонку на несколько новых (исходная колонка сохраняется). Для каждой строки:

- **callback:** `iter_fn(cell)` → `array` частей;
- **или строка-разделитель:** `column, " ", ["Part1", "Part2"]` — встроенный split без callback.

Недостающие части заполняются пустой строкой `""`. Новые колонки добавляются в конец таблицы.

**Аргументы:**
- `table` (table)
- `column` (string) — колонка-источник
- `iter_fn` (callable, arity 1) **или** `delimiter` (string)
- `new_columns` (array of string) — имена новых колонок (непустой массив)

**Примеры:**
```datacode
table_split_column(data, "FullName", " ", ["First", "Last"])
data.split_column("Tag", fn(x) => [x, ""], ["A", "B"])
```

**Ошибки:** `KeyError`, `ValueError` (пустой `new_columns`, дубликат имени), `TypeError` (callback не array).

---

### `table_join_columns(table, source_columns, new_column, delimiter)` / `table.join_columns(...)`

Склеивает несколько колонок в одну новую (`join` по значениям строки). Исходные колонки сохраняются.

**Аргументы:**
- `table` (table)
- `source_columns` (array of string) — колонки в порядке склейки
- `new_column` (string) — имя новой колонки
- `delimiter` (string) — разделитель

**Примеры:**
```datacode
table_join_columns(employees, ["Name", "Department"], "NameDept", " — ")
employees.join_columns(["Name", "Department"], "NameDept", " - ")
```

**Ошибки:** `KeyError`, `ValueError` (пустой список колонок, имя уже существует).

### `table_sort(table, column, ascending)`

Сортирует таблицу по указанной колонке.

**Аргументы:**
- `table` (table) - таблица
- `column` (string) - название колонки для сортировки
- `ascending` (bool, опционально) - направление сортировки (по умолчанию `true`)

**Возвращает:** `table` - новая отсортированная таблица, или `null` если колонка не найдена или аргументы неверного типа

**Примеры:**
```datacode
table_sort(data, "Age")              # По возрастанию
table_sort(data, "Name", true)       # По возрастанию
table_sort(data, "Salary", false)    # По убыванию

```

### `table_where(table, column, operator, value)`

Фильтрует таблицу по условию.

**Аргументы:**
- `table` (table) - таблица
- `column` (string) - название колонки для фильтрации
- `operator` (string) - оператор сравнения (">", "<", ">=", "<=", "==", "=", "!=", "<>")
- `value` (any) - значение для сравнения

**Возвращает:** `table` - новая таблица с отфильтрованными строками, или `null` если колонка не найдена или аргументы неверного типа

**Примеры:**
```datacode
table_where(data, "Age", ">", 18)
table_where(data, "Name", "==", "John")
table_where(data, "Salary", ">=", 50000)
table_where(data, "Status", "!=", "inactive")

```

**Альтернативный синтаксис:** фильтр через скобки — `data["Age" > 25]`. Поддерживаются `in` / `not in`, строковые условия `& contains(...)` и составные условия:

```datacode
data["City" in ["Houston", "Chicago"]]
data["Name" & starts_with("Jo")]
data["Name" & ends_with("son")]
data["Salary" & contains("50000")]
data["Age" > 25 or "City" == "Houston"]
data["Age" > 25 and "City" == "Houston"]
data[("Age" > 25 or "City" == "Houston") and "Salary" > 40000]
```

Приоритет: `and` выше `or`. Цепочка `[...][...]` эквивалентна `and`.

### `table_drop_nulls(table, column?)`

Удаляет строки, содержащие `null` в указанных колонках.

**Аргументы:**
- `table` (table) — таблица
- `column` (string | array[string], опционально) — одна колонка или список колонок для проверки

**Поведение:**
- Без `column` — удаляется строка, если **хотя бы в одной** колонке `null`
- С `column` — удаляется строка, если `null` в **любой** из указанных колонок

**Возвращает:** `table` — новая таблица без удалённых строк (исходная не изменяется)

**Примеры:**
```datacode
table_drop_nulls(data)
table_drop_nulls(data, "City")
table_drop_nulls(data, ["City", "Age"])

data.drop_nulls()
data.drop_nulls("City")
data.drop_nulls(["City", "Age"])
```

**Ошибки:** `TypeError` если `column` не строка и не массив строк; `KeyError` если колонка не найдена.

---

### `table_replace_nulls(table, column_or_replacement, replacement?)`

Заменяет ячейки со значением `null` на константу или результат callback.

**Аргументы:**
- `table` (table) — таблица
- `column_or_replacement` (string | array[string] | any | function) — селектор колонок или значение/функция замены
- `replacement` (any | function, опционально) — значение/функция замены, если второй аргумент задан как колонка(и)

**Поведение:**
- `table_replace_nulls(data, replacement)` — заменить `null` во **всех** колонках
- `table_replace_nulls(data, "City", replacement)` — заменить `null` только в колонке `City`
- `table_replace_nulls(data, ["City", "Age"], replacement)` — заменить `null` только в перечисленных колонках
- `replacement` может быть:
  - скалярным значением
  - callback `fn(row)`, где `row` — объект текущей строки (`{"Column": value, ...}`)

**Возвращает:** `table` — новая таблица с заменами (исходная не изменяется)

**Примеры:**
```datacode
table_replace_nulls(data, "Unknown")
table_replace_nulls(data, "City", "Unknown")
table_replace_nulls(data, ["City", "Age"], "Unknown")

table_replace_nulls(data, ["City", "Age"], fn(row) => if row["Amount"] < 1000 { null } else { "Unknown" })

data.replace_nulls("Unknown")
data.replace_nulls("City", "Unknown")
data.replace_nulls(["City", "Age"], "Unknown")
```

**Ошибки:** `TypeError` при неверном типе `column`, неверной арности callback или неверном числе аргументов; `KeyError` если колонка не найдена.

### `table_row_number(table, column_name?, start_from?)`

Добавляет в таблицу новую колонку с последовательной нумерацией строк.

**Аргументы:**
- `table` (table) — таблица
- `column_name` (string, опционально) — имя новой колонки (по умолчанию: `"RowNumber"`)
- `start_from` (number, опционально) — начальное значение (по умолчанию: `1`)

**Возвращает:** `table` — новую таблицу с добавленной колонкой нумерации

**Примеры:**
```datacode
table_row_number(data)
table_row_number(data, "Num")
table_row_number(data, "Num", 100)

data.row_number()
data.row_number("Num", 100)
```

**Ошибки:** `TypeError` при неверных типах аргументов; `ValueError` если колонка `column_name` уже существует.

### `table_distinct(table, columns?)`

Удаляет дубли строк с сохранением порядка первого вхождения.

**Аргументы:**
- `table` (table) — таблица
- `columns` (string | array[string], опционально) — колонка или список колонок для ключа уникальности

**Поведение:**
- Без `columns` — удаляет дубли по **всей строке**
- С `columns` — удаляет дубли по значениям указанных колонок

**Возвращает:** `table` — новую таблицу без дублей

**Примеры:**
```datacode
table_distinct(data)
table_distinct(data, "ID")
table_distinct(data, ["ID", "Category"])

data.distinct()
data.distinct(["ID", "Category"])
```

**Ошибки:** `TypeError` если `columns` не строка и не массив строк; `KeyError` если колонка не найдена.

---

### `table_value_map(table, column, mappings)`

Преобразует значения в одной колонке таблицы по правилам mapping.

**Аргументы:**
- `table` (table) — таблица
- `column` (string) — имя целевой колонки
- `mappings` (object | array[object]) — правила замены значений

**Поддерживаемые форматы mappings:**
- object: `{old_value: new_value, ...}`
- array: `[{"from": x, "to": y}, ...]` или `[{old: x, new: y}, ...]`

Значения, которых нет в mappings, остаются без изменений.

**Возвращает:** `table` — новую таблицу с преобразованной колонкой

**Примеры:**
```datacode
table_value_map(data, "Active", {"yes": "active", "no": "inactive"})
table_value_map(data, "Tag", [{"from": "sale", "to": "promo"}, {"from": "new", "to": "fresh"}])
data.value_map("Tag", [{old: "old", new: "archive"}])
```

**Ошибки:** `TypeError` при неверных типах аргументов или неверном формате элемента mapping; `KeyError` если `column` не найдена.

---

### `table_aggregate(table, spec)`

Агрегирует всю таблицу в новую таблицу с одной строкой результата.

**Аргументы:**
- `table` (table) — исходная таблица
- `spec` (object) — объект формата `{output_column: aggSpec, ...}`

Формы `aggSpec`:
- строка: `"count"` (для операций без колонки)
- объект: `{op: "...", column: "Amount", ...}`

Поддерживаемые операции:
- `count`, `count_distinct`, `sum`, `avg`, `min`, `max`, `first`, `last`, `median`, `mode`, `stddev`, `variance`, `percentile`, `list`, `any`

Спец-поля:
- `percentile`: `{op: "percentile", column: "Amount", p: 0.9}`
- `any`: `{op: "any", column: "Amount", where: fn(x) => x > 100}`

**Возвращает:** `table` — новую таблицу с одной строкой и колонками из ключей `spec`

**Примеры:**
```datacode
summary = table_aggregate(employees, {
  rows: "count",
  total_amount: {op: "sum", column: "Amount"},
  p90_amount: {op: "percentile", column: "Amount", p: 0.9},
  has_large: {op: "any", column: "Amount", where: fn(x) => x > 6000}
})

summary2 = employees.aggregate({
  rows: "count",
  avg_amount: {op: "avg", column: "Amount"}
})
```

**Ошибки:** `TypeError` для неверного `spec`/`op`/типов полей; `KeyError` если `column` не найдена.

---

### `table_aggregate_group(table, spec)`

Группирует строки таблицы и агрегирует каждую группу в отдельную строку результата.

**Аргументы:**
- `table` (table) — исходная таблица
- `spec` (object) — объект с обязательным полем `group` и агрегациями (тот же формат `aggSpec`, что у `table_aggregate`)

**Обязательное поле:**
- `group` (string | array[string]) — колонка или список колонок для группировки

**Возвращает:** `table` — новую таблицу с одной строкой на каждую уникальную группу; сначала group-колонки, затем колонки агрегаций

**Примеры:**
```datacode
by_city = table_aggregate_group(employees, {
  group: "City",
  count: "count",
  sum_amount: {op: "sum", column: "Amount"},
})

by_dept_city = employees.aggregate_group({
  group: ["Department", "City"],
  count: "count",
  avg_amount: {op: "avg", column: "Amount"},
})
```

**Ошибки:** `TypeError` для неверного `spec`/`group`/полей агрегации; `KeyError` если group-колонка или колонка агрегации не найдена.

### `table.add_row(row)` (метод)

Добавляет строку в существующую таблицу **in-place**. Глобальной функции `table_add_row` нет — только синтаксис метода.

**Аргументы:**
- `row` (array) — массив значений ячеек; длина должна совпадать с числом колонок

**Возвращает:** `table` — та же таблица (мутация in-place)

**Примеры:**
```datacode
t = table([[1, "a"]], ["id", "name"])
t.add_row([2, "b"])
len(t)   # 2

# Пустая таблица с заголовками
t = table([], ["x", "y"])
t.add_row([1, 2])

```

**Ошибки:** `TypeError` если аргумент не массив; `ValueError` если длина строки не совпадает с числом колонок.

**📚 Пример:** [`examples/ru/03-типы данных/05-add_row.dc`](../../../examples/ru/03-типы%20данных/05-add_row.dc)

### `relate(pk_col, fk_col, ...)` / `relate([pk_col, fk_col, ...])`

Объявляет связи между колонками (для модели данных / экспорта в SQLite).

**Семантика «звезда»:** **первая** колонка — сторона первичного ключа (target); каждая следующая — внешний ключ (source) на неё.

```datacode
relate(users["id"], orders["user_id"])
# то же, что два вызова:
relate(users["id"], orders["user_id"], invoices["user_id"])
relate([users["id"], orders["user_id"], invoices["user_id"]])
```

**Аргументы:**
- две или более ссылки на колонки позиционными аргументами, **или**
- один массив ссылок на колонки

Меньше 2 колонок, не-колонка или смешение массива с лишними аргументами — `TypeError`.

### `primary_key(col)`

Помечает колонку как первичный ключ таблицы.

**Аргументы:**
- `col` — ссылка на колонку

### `save_tables_sqlite(tables, filename="db", **kwargs)`

Экспорт массива таблиц в один SQLite-файл. Связи `relate` и `primary_key` учитываются в схеме. Дополнительные kwargs попадают в `_datacode_variables`.

**Аргументы:**
- `tables` (array) — массив таблиц (каждая должна быть в именованной переменной)
- `filename` (string, опционально) — базовый путь (добавляется `.sqlite`)
- `**kwargs` — произвольные метаданные

**Возвращает:** `string` — итоговый путь к файлу

**Пример:**
```datacode
users = table([[1, "Alice"]], ["id", "name"])
orders = table([[1, 100]], ["user_id", "amount"])
invoices = table([[1, 10]], ["user_id", "total"])
relate(users["id"], orders["user_id"], invoices["user_id"])
# или: relate([users["id"], orders["user_id"], invoices["user_id"]])
path = save_tables_sqlite([users, orders, invoices], filename="model", env="dev")
```

Подробнее: [таблица.md](../типы-данных/таблица.md#функция-save_tables_sqlitetables-filenamedb-kwargs)
