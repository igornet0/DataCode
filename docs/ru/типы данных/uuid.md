# UUID

**UUID** — 128-битный идентификатор (внутри хранится как два 64-битных числа). Удобен для уникальных ключей и обмена с нативными библиотеками.

`typeof` → **`"uuid"`**.

Проверка: `isinstance(x, "uuid")` — [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Что можно делать в языке

- Сравнивать на равенство **`==`**, если два UUID считаются одним и тем же значением.
- Передавать в функции API, которые ожидают UUID.

Обращения вида **`uuid["поле"]`** в ядре **не** поддерживаются — нет списка именованных свойств на значении UUID.

---

## Откуда берётся UUID

В списке встроенных глобальных функций **нет** отдельного конструктора `uuid(...)` для произвольной строки (на момент описания документации). Обычно UUID приходят из:

- вызовов внешнего API;
- нативных модулей (`.dylib` / `.so`);
- библиотек проекта.

---

## `len`

Для UUID функция **`len`** не определена (ожидаемо вернётся «пустой» результат для неподдерживаемого типа).
