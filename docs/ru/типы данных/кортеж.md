# Кортеж (`tuple`)

Кортеж — это **фиксированная по смыслу** последовательность значений: порядок важен, как в математической паре `(x, y)` или в возврате нескольких значений из логики перечисления.

`typeof` → **`"tuple"`**.

Проверка: `isinstance(x, "tuple")` — [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Индексация

Только **неотрицательный** целый индекс: `t[0]`, `t[1]`, …

**Отрицательных индексов нет** (в отличие от массива) — `t[-1]` приведёт к ошибке.

Строковых методов вида `t["имя"]` у кортежа **нет**.

```dc
# Пример: элемент перечисления enum — кортеж (индекс, значение)
let e = enum([10, 20])
let pair = e[0]
print(pair[0])   # 0
print(pair[1])   # 10
```

---

## Встроенные функции

- **`len(t)`** — число элементов.
- **`enum(t)`** — обёртка для цикла с индексом (см. [массивы.md](массивы.md)).

---

## Отличие от массива (на практике)

| | Массив | Кортеж |
|---|--------|--------|
| `map` / `filter` / `reduce` | да | нет (нужно иметь массив или view) |
| Отрицательный индекс | да | нет |
| `push` / мутации списка | да | не через типичный API массива |

Если нужна гибкая обработка — чаще работают с **массивом**; кортеж удобен как **небольшой составной результат**.
