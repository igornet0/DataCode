# Объект (словарь, класс, служебные дескрипторы)

**Объект** — это набор пар **имя → значение**. В DataCode им пользуются и как обычным **словарём**, и как **экземпляром класса** или **классом**, и иногда как служебной структурой (плагины, дескрипторы типов).

`typeof` обычно → **`"object"`**, либо строка из **`__plugin_namespace`** для объектов плагина.

Проверка типов и классов: [typeof-и-isinstance.md](typeof-и-isinstance.md).

---

## Доступ к полям

- **`obj["ключ"]`**
- **`obj.ключ`** (если синтаксис языка это допускает для данного идентификатора)

Для **классов** действуют ограничения **private** / **protected** и особые правила для **`metadata`** — см. реализацию `get_object` в `object_fields.rs`.

Пример словаря:

```dc
let user = {"name": "Ann", "age": 20}
print(user["name"])
```

---

## Встроенные функции

| Функция | Назначение |
|---------|------------|
| `len(obj)` | Сколько ключей |
| `isinstance(obj, Класс)` | Проверка класса / наследования (второй аргумент — объект класса с `__class_name`) |
| `isinstance(obj, "object")` | Любой обычный объект-словарь |
| `isinstance(obj, "table")` | Объект **класса**, наследующего табличную модель (`Table`) |

Исключения: конструирование сообщения **`ValueError(...)`** через встроенный натив (см. документацию языка по `raise`).

---

## Таблицы и классы

Классы могут наследовать встроенный **`Table`**. Тогда экземпляр может вести себя как строка таблицы с полями-колонками, а `isinstance(..., "table")` — см. [таблица.md](таблица.md).

---

## Дескриптор `str[N]`

Конструкция **`str[5]`** у глобальной **`str`** возвращает не строку из пяти символов, а **объект** с полями вроде **`__type`**, **`__length`** — для описания типа «строка фиксированной длины» в ORM/схемах. См. [строка.md](строка.md).
