# Таблица и колонка

Таблица — это именованные **колонки** и **строки** данных (как упрощённая таблица из Excel или SQL-результата). Отдельный тип **колонка** появляется, когда вы берёте одну колонку из таблицы: с ней можно работать как с «виртуальным массивом» в функциях `sum`, `len` и т.д.

Подробно про проверку типов для **любых** значений, включая таблицы: **[typeof и isinstance](typeof-и-isinstance.md)**.

---

## Таблица (`table`)

### Зачем нужна

- хранить данные в строках и колонках;
- фильтровать, сортировать, смотреть первые/последние строки;
- соединять с другими таблицами (джойны);
- наследовать классы от встроенного **`Table`** в объектной модели.

`typeof(таблица)` → строка `"table"`.

### Как создать

Обычно через функцию **`table(...)`** (см. документацию по функции в проекте). Пример идеи:

```dc
# Сначала строки (массив массивов), затем при необходимости — заголовки
let t = table([["Ann", 20], ["Bob", 25]], ["name", "age"])
print(len(t))                    # число строк
print(t["columns"])              # массив имён колонок
```

### Обращение по индексу `t[...]`

| Выражение | Что получится |
|-----------|----------------|
| `t["имя_колонки"]` | **Колонка** (ленивая ссылка): потом можно писать `col[i]` для ячейки |
| `t["rows"]` | Массив строк (каждая строка — массив или объект полей) |
| `t["columns"]` | Массив строк — имена колонок |
| `t[0]`, `t[1]`, … | **Объект** (словарь) одной строки: ключ = имя колонки |

Пример:

```dc
let col = t["age"]
print(len(col))                  # сколько строк в этой колонке
let row0 = t[0]
print(row0["name"])              # значение в колонке name для первой строки
```

Если колонки с таким именем нет — будет ошибка вида «column not found».

### Встроенные функции для таблиц

**Просмотр и преобразование:** `table`, `table_info`, `table_head`, `table_tail`, `table_select`, `table_sort`, `table_where`, `show_table`, `merge_tables`.

**Соединение таблиц:** `inner_join`, `left_join`, `right_join`, `full_join`, `cross_join`, `semi_join`, `anti_join`, `zip_join`, `asof_join`, `apply_join`, `join_on`, `table_suffixes`.

**Связи:** `relate`, `primary_key`.

**Класс для наследования:** глобальный идентификатор **`Table`** — используется в объявлениях классов, наследующих табличную модель; для проверки типа см. ниже.

### Функция `join`

- Если первый аргумент — **таблица** и аргументов не меньше трёх, вызывается **соединение таблиц** (table join).
- Если первый аргумент — **массив строк** и второй — разделитель, строки **склеиваются** в одну строку (как «join» для массива).

## Колонка таблицы (`column`)

Появляется как результат `t["col"]`. Это не отдельный литерал в языке, а внутренний тип «ссылка на колонку».

`typeof(колонка)` → `"column"`.

### Индексация

- `col[i]` — значение ячейки в строке с номером `i` (нумерация с нуля, как у строк таблицы).

### Встроенные функции

Там, где это реализовано, первым аргументом можно передать колонку:

- **`len(col)`** — число строк;
- **`sum`**, **`average`**, **`count`**, **`unique`** — агрегаты по колонке (для чисел и уникальных значений — см. реализацию).

Пример:

```dc
let ages = t["age"]
print(sum(ages))
print(unique(ages))
```

## Проверка типа: таблица и классы

Функция **`isinstance`** описана для **всех типов** в [typeof-и-isinstance.md](typeof-и-isinstance.md).

Кратко для таблиц:

```dc
print(isinstance(t, "table"))     # true для встроенной таблицы
print(isinstance(t, Table))       # то же для значения-таблицы (через класс Table)
```

Для **объекта класса**, объявленного с наследованием от **`Table`**, `isinstance(obj, "table")` может быть **true**, если у объекта выставлен внутренний признак наследования от таблицы (`__extends_table`). Подробности — в [объект.md](объект.md).
