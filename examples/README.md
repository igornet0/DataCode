## 🎯 Example Structure / Структура примеров

Examples are organized by topics, progressing from simple to complex (same numbering in both languages):

Примеры организованы по темам, от простого к сложному (одинаковая нумерация в обоих языках):

- **01-basics / 01-основы** — Basic language features / Основы языка
- **02-syntax / 02-синтаксис** — Language syntax constructs / Синтаксические конструкции
- **03-data-types / 03-типы данных** — Working with data types / Работа с типами данных
- **04-functions / 04-функции** — Function creation and usage / Создание и использование функций
- **05-demonstrations / 05-демонстрации** — Comprehensive demonstrations / Комплексные демонстрации
- **06-loops / 06-циклы** — Loop constructs / Конструкции циклов
- **07-websocket** — WebSocket server examples / Примеры WebSocket сервера
- **08-data-model-creation / 08-создание модели данных** — Building data models / Создание моделей данных
- **09-advanced / 09-продвинутые** — Advanced programming techniques / Продвинутые техники
- **10-plot / 10-графики** — Plots and visualization / Графики и визуализация
- **11-settings-env / 11-settings_env** — settings_env module / Модуль settings_env
- **12-uuid / 12-uuid** — UUID module / Модуль UUID
- **13-database / 13-database** — Database module / Модуль database
- **14-modules / 14-модули** — Modules and packages / Модули и пакеты
- **15-datasource** — HTTP / file / SQLite DataSource
- **16-crypto / 16-крипто** — Cryptography globals and `crypto` module
- **17-process-gpu** — `system` GPU and benchmarks
- **18-debug** — VM debugging (`debug.operators()`)

## 🚀 Quick Start / Быстрый старт

### Running Examples / Запуск примеров

```bash
# English
datacode examples/en/01-basics/hello.dc

# Russian
datacode examples/ru/01-основы/привет.dc
```

### Recommended Learning Path / Рекомендуемый путь обучения

1. **Start with basics / Начните с основ**
2. **Learn syntax / Изучите синтаксис**
3. **Master functions / Освойте функции**
4. **Study loops / Изучите циклы**
5. **Advanced techniques / Продвинутые техники**
6. **Modules and packages / Модули и пакеты**
7. **Full demonstration / Полная демонстрация**
