## Быстрый старт

```bash
# 1. Первый скрипт
datacode examples/ru/01-основы/привет.dc

# 2. Условия
datacode examples/ru/02-синтаксис/условия.dc

# 3. Функции (по номерам внутри папки)
datacode examples/ru/04-функции/01-простые_функции.dc

# 4. Циклы
datacode examples/ru/06-циклы/01-циклы_for.dc

# 5. Полная демо
datacode examples/ru/05-демонстрации/01-демонстрация.dc
```

## Нумерация файлов внутри папок

В разделах **04-функции**, **06-циклы**, **10-графики**, **11-settings_env**, **12-uuid**, **08-создание модели данных** файлы пронумерованы `01-…`, `02-…` — проходите по порядку.
