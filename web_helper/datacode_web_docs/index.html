Что такое DataCode?

DataCode — язык для обработки данных: таблицы, файлы, JOIN, встроенные модули и простой синтаксис с фигурными скобками. 117 глобальных функций, методы у типов (s.upper(), t.select()) и пакеты DPM.

Простой пример

DataCode 
let name = "DataCode"
let nums = [1, 2, 3, 4, 5]

print("Привет, ${name}!")

for item in nums {
    print("Число:", item, "Квадрат:", item * item)
}

print(nums.sum())
print("hello".upper())

09. Классы

DataCode
cls Point {
    public:
        x: int
        y: int
    new Point(x, y) {
        this.x = x
        this.y = y
    }
    fn @string() -> str {
        return "Point(${this.x}, ${this.y})"
    }
}

Типы данных и методы

Почти у каждого типа есть методы: s.upper() ≡ upper(s). Редактор подсказывает методы после точки, если тип переменной известен.

Строка

Двойные кавычки. s[i] — Unicode-символ (без отрицательного индекса у одиночного индекса). Срезы s[a:b:step] поддерживают отрицательные индексы.

МетодРезультат
s.upper() / lower() / trim() / capitalize()string
s.split(delim)array
s.contains(sub) / isupper() / islower()bool
s.replace(find, repl)string

Массив

push pop unique reverse sort sum average count any all chunk clone map

x = [1]

Множество

set() / set(iterable): add remove discard pop clear copy update contains. Элементы должны быть hashable.

Таблица и колонка

Методы таблицы: add_row select rename drop_column add_column map split_column join_columns drop_nulls replace_nulls row_number distinct value_map aggregate aggregate_group sort.

Date и duration

Поля date (скобки необязательны): year month day quarter hour minute second weekday utc / to_utc. Метод d.format("%Y-%m-%d").

date ± duration → date, date - date → duration.

Path, archive, bytes, uuid

  • path: свойства name parent exists is_file is_dir extension через p["name"]. len(p) не задан — используйте path_len(p).
  • archive: read read_text extract close + свойства files count size.
  • bytes: len, индекс 0..255, не итерируется. str(sha256(…)) — hex.
  • uuid: создаётся модулем uuid (v4, v7, parse).

DataSource и response

datasource: request get_table send_table connect disconnect ping test clone.

response: свойства status success url headers body text bytes; методы json table csv save.

Генератор

g.next(), g.send(v), g.final(), свойство g.live.

Специальные методы класса

Не вызываются как obj.@string(). Подключаются к операторам: @string @len @add @sub @mul @div @mod @pow @eq @get @set @contains @call @iter @next @clone @hash @init.

Встроенные функции

117 глобальных функций из BUILTIN_GLOBAL_NAMES. Алиасы: read → read_file, read_bin → read_file_bin. Extended: save, save_tables_sqlite.

Многие функции дублируются методами типов: upper(s) ≡ s.upper().

Таблицы и JOIN

Таблицы создаются через table(), read() / read_file() или JOIN. Запись колонки: t!["new"] = values. Фильтр: t["Age" > 25], t["City" in ["NY", "LA"]].

employees!["vat"] = 0.2

Пример JOIN

DataCode
users = table([[1, "Alice"], [2, "Bob"], [3, "Charlie"]], ["id", "name"])
orders = table([[1, 100], [1, 200], [3, 300]], ["user_id", "amount"])

show_table(inner_join(users, orders, "id", "user_id"))
show_table(left_join(users, orders, "id", "user_id"))
show_table(anti_join(users, orders, "id", "user_id"))

join(array, delim) склеивает строки. Если первый аргумент — таблица, join выполняет табличный JOIN.

Протокол DCP

Запрос — binary кадр с байтами .dcp (magic DCPK). Ответ — JSON:

JSON
{
  "success": true,
  "output": "2 + 2 = 4\n",
  "error": null
}
Bash
dcp create -o job.dcp --code script.dc --assets-dir ./data

С --build_model в ответе может быть sqlite_db (base64). Примеры: examples/ru/07-websocket/.
