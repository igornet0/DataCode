# DataCode Web Editor

Современный веб-редактор кода для языка DataCode с подсветкой синтаксиса, автодополнением и красивым дизайном в стиле Cyberpunk/VSCode.

## 🎨 Особенности

- **Подсветка синтаксиса** - Полная поддержка синтаксиса DataCode с неоновыми цветами
- **Автодополнение (IntelliSense)** - Умные подсказки для ключевых слов, функций и переменных
- **Множественные вкладки** - Работа с несколькими файлами одновременно
- **Поиск и замена** - Быстрый поиск по коду (Ctrl+F)
- **История изменений** - Undo/Redo для отмены действий
- **Консоль вывода** - Панель для вывода результатов выполнения
- **Современный дизайн** - Темная тема в стиле Cyberpunk с неоновыми акцентами
- **Адаптивный интерфейс** - Работает на разных размерах экрана

## 🚀 Использование

### Простой запуск

1. Откройте `index.html` в современном браузере (Chrome, Firefox, Edge, Safari)
2. Начните писать код в редакторе

### Локальный сервер (рекомендуется)

Для лучшей работы рекомендуется запустить локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен http-server)
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте в браузере: `http://localhost:8000`

## ⌨️ Горячие клавиши

- **Ctrl+F** (Cmd+F на Mac) - Открыть панель поиска
- **Ctrl+Z** (Cmd+Z) - Отменить действие
- **Ctrl+Y** или **Ctrl+Shift+Z** - Повторить действие
- **Tab** - Вставить отступ (4 пробела)
- **Shift+Tab** - Убрать отступ
- **Enter** или **Tab** (в автодополнении) - Принять предложение
- **↑/↓** (в автодополнении) - Навигация по предложениям
- **Escape** - Закрыть автодополнение

## 📝 Поддерживаемый синтаксис DataCode

### Ключевые слова
- `global`, `let` - Объявление переменных
- `fn` - Определение функций (используются фигурные скобки `{ }`)
- `if`, `else` - Условные конструкции (используются фигурные скобки `{ }`)
- `for`, `in`, `while` - Циклы (используются фигурные скобки `{ }`)
- `return` - Возврат значения
- `try`, `catch`, `finally`, `throw` - Обработка ошибок (используются фигурные скобки `{ }`)
- `break`, `continue` - Управление циклами
- `import`, `from`, `as` - Импорт модулей
- `cache` - Кэширование
- `true`, `false`, `null` - Логические значения

### Синтаксис блоков
Все блоки кода используют фигурные скобки `{ }`:
```dc
fn my_function() {
    if condition {
        // код
    } else {
        // код
    }
    
    for item in array {
        // код
    }
    
    while condition {
        // код
    }
    
    try {
        // код
    } catch e {
        // обработка ошибки
    } finally {
        // код очистки
    }
}
```

### Строки
Поддерживаются как одинарные, так и двойные кавычки:
```dc
let str1 = 'Hello'
let str2 = "World"
```

### Объекты
Поддерживается синтаксис объектов (словарей):
```dc
let obj = {
    key: 'value',
    number: 42,
    nested: {
        inner: 'data'
    }
}
```

## 🔧 Настройка

### Изменение цветовой схемы

Отредактируйте переменные CSS в `styles.css`:

```css
:root {
    --neon-purple: #B026FF;
    --neon-cyan: #00D9FF;
    --bg-primary: #0D0F14;
    /* ... другие цвета ... */
}
```

### Добавление новых функций в автодополнение

Отредактируйте массив `builtinFunctions` в `syntax-highlighter.js`:

```javascript
this.builtinFunctions = [
    // ... существующие функции ...
    'your_new_function'
];
```

## 🐛 Известные ограничения

- Поиск и замена работает базово (можно улучшить)
- Нет интеграции с реальным интерпретатором DataCode (только редактор)
- Мини-карта кода не реализована полностью
- Нет сохранения файлов на диск (работает только в браузере)
